Review of Red-Blue Dominating Set by treewidth · Effective little-o bound in the treewidth under FPT ≠ W[1] · r1

Reviewed scope

Forward implication for intrinsic treewidth. Logarithmic-treewidth Red-Blue Dominating Set is XALP-hard, so it is W[1]-hard. The edge-subdivision construction has an explicit blue/red partition. Discard the supplied decomposition. For a Clique input of order n and parameter k, the output treewidth is at most g(k)⁢(1+log2⁢n)g(k)(1+log₂ n) for a computable g. Use the computable cutoff for a slope at most 1/g(k)1/g(k). Above the cutoff the exponential factor is polynomial in n, and below it the computable exponent has a finite maximum controlled by k. The polynomial-size reduction output then gives an FPT algorithm for Clique.
