Hypotheses

FPT ≠ W[1]

Statement

There exists a parameterized decision problem in W[1] for which no deterministic algorithm runs in time f(k)⁢LCf(k) L^C for any computable function f and constant C, where k is the parameter and L is the input length in bits.

Source for the class definitions

Fixed-Parameter Tractability and Completeness I: Basic Results · Rod G. Downey, Michael R. Fellows · SIAM Journal on Computing 24(4) (1995), 873–921 · Definition 1.9, p. 874, and Definitions 3.5–3.6, p. 882 · Open full text

Identifier
w1
Revision
1
Aliases
deterministic W[1] separation
Model
Deterministic uniform algorithms on explicitly encoded inputs, under fixed-parameter reductions.
Quantifiers
An FPT algorithm has time f(k)·LCf(k) · L^C for a computable function f, a fixed constant C, parameter k, and complete input length L.
Conventions
No restriction to polynomial, elementary or quasipolynomial growth of f. Randomized separation would be another premise.
