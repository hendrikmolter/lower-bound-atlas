Exponential Time Hypothesis (ETH)

Original ETH

There exists δ>0δ > 0 such that, for every fixed C≥0C ≥ 0, no deterministic algorithm decides 3-SAT in time 𝒪(2δ⁢n⁢LC)O(2^(δ n) L^C), where n is the number of variables and L is the input length in bits.

Uniform ETH

No single deterministic algorithm decides 3-SAT in time 2o(n)⁢L𝒪(1)2^(o(n)) L^(O(1)), where n is the number of variables and L is the input length in bits.

Chen, Eickmeyer and Flum · Cite this formulation

Strongly uniform ETH

No single deterministic algorithm decides 3-SAT in time 2oeff(n)⁢L𝒪(1)2^(o_eff(n)) L^(O(1)), where n is the number of variables and L is the input length in bits.

Chen, Eickmeyer and Flum · Cite this formulation

Historical status

Original ETH implies uniform ETH, which in turn implies strongly uniform ETH. The 2026 preprint refutes all three because its deterministic 3-SAT algorithm has an effectively sublinear exponent. The Exponential Time Hypothesis is False.

Recovery under another hypothesis

If a lower bound implies strongly uniform ETH, the refutation rules out recovering that bound from any true hypothesis. For a bound excluding only algorithms with an effectively sublinear exponent, this implication must hold for that version of the bound.
