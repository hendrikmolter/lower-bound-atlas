Hypotheses

Satisfiability Hypothesis (SH)

Statement

For every fixed 0<a<10 < a < 1, no deterministic algorithm decides CNF-SAT in time 2𝒪(na)·poly(n)2^O(n^a) · poly(n), where n is the normalized encoding length of the formula.

Defining source

Power indices and easier hard problems · Richard E. Stearns, Harry B. Hunt III · Mathematical Systems Theory 23(4) (1990), 209–225 · Definition 2.1, p. 210, and Satisfiability Hypothesis, §2, p. 213

Record details
Identifier
sh
Revision
1
Aliases
SH, SAT power index one
Model
Explicit CNF-SAT with the source encoding length as the size measure.
Quantifiers
For each fixed 0<a<10 < a < 1 there is no deterministic 2𝒪(na)·poly(n)2^O(n^a) · poly(n) SAT algorithm, with n the normalized input length.
Conventions
Whole fixed-power exclusion family. Conversions to variable count, clause count or combinatorial length require the stated normalization or sparsification argument.
Source note
Stearns and Hunt introduced SH. For the normalized length convention, see the introduction and footnotes 1–2 in arXiv:2611.02650v2, pp. 1–2.
