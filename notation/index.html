Notation

Default algorithmic model

Uniform deterministic bit algorithm with worst-case running time. Individual bounds specify any exceptions.

Effective little-o

For a scale s(t)s(t), write h(t)=oeff(s(t))h(t) = o_eff(s(t)) if there is a total computable function T such that h(t)≤s(t)/jh(t) ≤ s(t)/j for every positive integer j and all t≥T(j)t ≥ T(j). Here j specifies the required accuracy and T(j)T(j) is the threshold beyond which the inequality holds.

Exponents are finite and nonnegative. The threshold must be computable even when the exponent itself is not. Any additional requirement on the exponent is stated beside the running time.

When the exponent also depends on a parameter

For h(d,q)h(d,q), one procedure computes T(q,j)T(q,j) from the parameter q and the accuracy index j. For every q≥2q ≥ 2 and j≥1j ≥ 1, all d≥T(q,j)d ≥ T(q,j) must satisfy h(d,q)≤d/jh(d,q) ≤ d/j. The threshold may depend on q.

A computable upper envelope is a total computable function H with h(d,q)≤H(d,q)h(d,q) ≤ H(d,q) for every pair of arguments. In the Closest String theorem it also bounds the exponent below the convergence threshold. The exponent h itself need not be computable.
