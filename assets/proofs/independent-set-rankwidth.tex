In \textsc{Independent Set}, we are given a simple undirected graph
and a nonnegative binary threshold and ask if there is an independent
set of at least that size. The cut rank of a vertex set is the rank over
\(\mathbb F_2\) of its adjacency matrix to the complement. The width of a
vertex order is the maximum cut rank of a prefix, and linear rank-width
is the minimum such width. A rank decomposition is a subcubic tree
whose leaves correspond to graph vertices. Its width is the maximum cut
rank of a split induced by a tree edge. Rank-width is the minimum such
width. An order gives a caterpillar rank decomposition with no larger
width except for the harmless bound of one on pendant cuts.

Let \(N\) be the complete binary input length, including a vertex
order or rank decomposition when supplied. The deterministic
Satisfiability Hypothesis (SH) excludes deterministic algorithms for
CNF-SAT in time \(O(2^{L^{1-\delta}})\) for every fixed
\(0<\delta<1\), where \(L\) is the formula's bit length~\cite{sh}.

\hypertarget{independent-set-rankwidth-sh}{}
\begin{theorem}\label{independent-set-rankwidth-sh}
Assume deterministic SH. For every fixed \(0<\epsilon<2\), no deterministic
algorithm decides \textsc{Independent Set} on triangle-free graphs
in \(2^{O(p^{2-\epsilon})}N^{O(1)}\) time. Here \(p\) is rank-width or
linear rank-width, separately. The exclusion also holds when the input
includes a rank decomposition or vertex order of width \(p\), even
on the promise that the supplied width is optimal.
\end{theorem}

Bergougnoux, Korhonen and Nederlof~\cite[Theorem 1.1]{bkn} establish
the quadratic ETH lower bound, parameterized by linear rank-width.
We use Molter's reduction~\cite[Sections 7.1--7.3]{molter} from
satisfiability to triangle-free graphs. It uses paths in place of
selection cliques to remove triangles and a small graph of large
rank-width to obtain an optimal certificate. We give the construction
and then derive the fixed-power exclusion from its size and width bounds.

\section{Encoding assignments in an independent set}

Take a CNF formula with \(v\) occurring variables and \(m\) clauses.
Normalize names and remove duplicate literals and tautologies.
An empty clause gives an immediate no answer, and a formula with no
remaining clauses gives an immediate yes answer. With
\(k=\lceil\sqrt{v}\rceil\), pad with unused variables to make \(k\) rows
of \(k\) variables each. Let \(B\) be an independent set with one
vertex for each \(z\in\mathbb F_2^{2k}\). For each clause \(i\) and
row \(j\) make a clique \(A_{i,j}\) with one vertex per assignment
\(a\in\mathbb F_2^k\). Its vector is \((e_j,a)\), with \(e_j\) the
unit vector at \(j\). Join it to \(z\) exactly when the dot product
is one. Make a clique \(T_i\) of the literals of each clause. Join a
literal vertex to assignments of its own row of that clause on
which it is false. There are no other edges. Use weight \(M=2^{2k}\)
on assignment vertices and weight one elsewhere. The threshold is
\(W=Mkm+2^k+m\).

The chosen vectors of one assignment matrix are linearly independent
by their first coordinates. Their common nonneighbors in \(B\) form
the orthogonal complement of their span and have size \(2^k\). This
subspace determines the assignment matrix, because in its orthogonal
complement the unique vector starting with \(e_j\) encodes row \(j\).
A satisfying assignment therefore gives an independent set of weight
\(W\) by selecting its row vertices in all layers, its common
nonneighbors in \(B\), and a true literal in each \(T_i\).
Conversely, any maximum-weight independent set hits every assignment
clique. Inserting a vertex of an unhit clique loses at most \(M/2\)
from \(B\) and one from the relevant \(T_i\), strictly less than \(M\).
After these forced choices, reaching \(W\) requires \(2^k\) vertices
of \(B\) and a literal in every \(T_i\). Thus all layers have the same
common nonneighbors in \(B\) and the same assignment. Its selected
literal in each clause is true.

\section{Removing triangles with constant additive width overhead}

Process \(B\) first, then, clause by clause and row by row, list
the vertices of \(A_{i,j}\) followed by the literals of that row of
\(T_i\). Remove the edges of each selection clique and retain its
vertices as markers in that order. For a clique of \(r\) markers
add a private path on \(2q\) sites with \(q=2r+2\). Marker \(j\)
is adjacent to sites \(4j\) and \(4j+3\). Give all path sites weight
\(U=1+\sum_{j=1}^{r}w_j\), where \(w_j\) are the original marker
weights. Keep the original intergroup edges and marker weights.

An optimum uses \(q\) sites on each path, since replacing fewer
sites and all selected markers by a maximum path set gains at
least \(U\) and loses at most \(U-1\). A maximum path set uses one
site in each pair \((2i-1,2i)\). It takes odd sites up to a split
\(t\) and even sites thereafter, because an even site followed
by an odd site in the next pair is forbidden. Marker \(j\) is
available exactly when \(2j\le t\le 2j+1\), and these intervals
are disjoint. Therefore at most one marker per former clique is
chosen, and any particular marker is permitted by some split.
The optimum increases by exactly \(\sum qU\) across all gadgets.
The graph is triangle-free because the old intergroup graph is
bipartite, each site touches at most one marker, and a marker's
two sites are three edges apart.

Before each marker \(j\), insert its path's as yet unplaced sites
through \(4j+3\). Insert each path's last site immediately after its
last marker.
For any cut in the resulting order, the intergroup edges among
old vertices have rank at most \(3k+1\). The parity edges between
\(B\) and assignment groups factor through \(2k\) coordinates.
Assignment-to-literal edges can cross only in the current row of
the current clause, and their columns are spanned by the \(k\)
coordinates and the all-ones column. At most two private paths
are split, one for the current assignment group and one for the
literal clique of the current clause. Each contributes at most
one path edge. Marker-to-site edges can cross only in the current
marker block, contributing at most two edges. Thus the width is
at most \(3k+5\).

Replace each vertex of weight \(w\) by \(w\) independent false twins,
and replace each edge by the complete join of its two classes.
The independent-set optimum is unchanged as a number after
interpreting the old objective as weight. Triangle-freeness is
preserved. Keep the twins consecutive. Cuts between classes repeat
rows and columns. A cut within a class introduces at most one
extra column type relative to the cut just after the class, so
the width is at most \(b=3k+6\). Site weights are \(1+2^{3k}\)
for assignment groups and at most \(1+v\) for literal groups.
All sizes and construction times, including writing the dense
graph and its certificate, are \(2^{O(k)}\) times a fixed polynomial
in the normalized formula length.

\section{Providing an optimal certificate}

We first construct a simple graph \(P\) on \(a=51200b\) vertices
with degree at most 16 and rank-width at least \(b\). For the
existence argument choose eight independent uniform permutations
and join every vertex to its image under each, omitting loops and
duplicates. For a fixed set \(S\) of size \(a/3\le r\le a/2\), let
\(t=\lfloor a/100\rfloor\). The probability that at most \(t\) of
its vertices map out under one permutation is at most
\[
 \binom rt(r/a)^{r-t}
 \le (50e)^{a/100}2^{-(a/3-a/100)}<2^{-a/5}.
\]
Indeed, one of the \(\binom rt\) subsets of size \(r-t\) must
map into \(S\), and its distinct images can be exposed in order.
The binomial bound uses the increase of \(x\ln(ea/(2x))\) up to
\(a/100\). For a fixed cut, if all eight permutations have at most
\(t\) outgoing images, independence bounds the probability of that
event by \(2^{-8a/5}\). A union bound over the cuts gives failure
probability at most \(2^a2^{-8a/5}<1\). A permutation with more
than \(t\) outgoing images provides that many distinct crossing
edges, so every balanced cut has more than \(a/100\) edges. Its crossing
graph has an induced matching of size at least \(a/51200\):
greedily keeping one edge and removing the neighborhoods of its
endpoints removes at most \(2\cdot16^2\) edges per choice.
The corresponding submatrix is a permutation matrix.
Every subcubic decomposition tree has an edge separating between
one third and one half of its leaves. Follow a branch with more
than half of the leaves as long as one exists. At the first
vertex with no such branch, a largest branch provides the cut.
Hence the rank-width is at least \(b\).
Enumerate tuples of permutations and test the stated cut condition
to find \(P\) deterministically in \(2^{O(b\log(b+2))}\) time.

Subdivide each edge of \(P\) once to obtain a bipartite graph \(P'\)
on \(O(b)\) vertices. Locally complement at each subdivision
vertex and delete it to restore the original edge. Local
complementation preserves cut ranks by adding the complemented
vertex's row to the rows of its neighbors on its own side, or
using columns if it is on the other side. Deletion cannot increase
either minimum width, by restricting an order or pruning a
decomposition tree. Therefore \(P'\) has rank-width at least \(b\).
Its linear rank-width is also at least \(b\), since a linear order
gives a caterpillar decomposition.

Enumerate subsets to compute \(\alpha(P')\) and every cut rank
\(\rho(S)\). To compute an optimum order, define \(D(\emptyset)=0\)
and \(D(S)=\max(\rho(S),\min_{x\in S}D(S\setminus\{x\}))\).
Choosing the last vertex of each prefix justifies the recurrence.
The optimum is \(D(V(P'))\), and minimizers recover an order.
For rank-width let \(E(\{x\})=\rho(\{x\})\), and for larger sets let
\[
 E(S)=\max\bigl(\rho(S),
       \min_{\emptyset\ne U\subsetneq S}\max(E(U),E(S\setminus U))\bigr).
\]
This is the optimum over rooted binary trees on the leaves \(S\):
choose the two child sets and use the cut rank of \(S\) at its root.
At the full set, forgetting the root and suppressing its
degree-two vertex gives a subcubic tree of the same width.
Conversely a subcubic decomposition can be rooted by subdividing
an edge and suppressing remaining degree-two vertices. The
split minimizers recover an optimum tree. Subset enumeration
and these recurrences take \(3^{O(b)}\) times a fixed polynomial.

Take the disjoint union with the triangle-free hard graph and
increase the threshold by \(\alpha(P')\). Concatenate the orders
or join the decomposition trees at subdivided edges. Each cut
then splits at most one graph. Because the optimum width of \(P'\)
is at least \(b\), the assembled certificate is optimal, by
induced-subgraph monotonicity. Its width is \(O(k)\). The total
construction costs \(2^{O(k\log(k+2))}\) times a fixed polynomial
in formula length, and the complete output length is
\(2^{O(k)}\) times a fixed polynomial.

\section{Transferring the running-time bound}

\begin{proof}[Proof of Theorem~\ref{independent-set-rankwidth-sh}]
Suppose an algorithm runs within the stated time bound for one of
the parameterizations and a fixed \(0<\epsilon<2\). Start with a 3-CNF
formula of variable-plus-clause count \(s\) and complete input length
\(L\). Under SH, this problem admits no deterministic
\(2^{O(s^{1-\gamma})}L^{O(1)}\)-time algorithm for any fixed
\(0<\gamma<1\)~\cite[Lemma 2.1]{sh}. With consecutive variable
identifiers the encoding length of a 3-CNF formula is polynomial
in \(s\), so the polynomial factor is absorbed in the exponential
bound on those inputs.

Apply the construction above. The independent set threshold is
attainable exactly when the formula is satisfiable. Supply the
corresponding optimal certificate if the algorithm takes one.
Since \(k=O(\sqrt{s})\), the width satisfies \(p=O(\sqrt{s})\), and the
construction takes \(2^{O(\sqrt{s}\log(s+2))}L^{O(1)}\) time.
The complete output length satisfies \(N=2^{O(\sqrt{s})}L^{O(1)}\).
The algorithm and the reduction together take
\(2^{O(s^{1-\gamma})}L^{O(1)}\) time for
\(\gamma=\min\{1/4,\epsilon/2\}>0\), contradicting SH.
\end{proof}
