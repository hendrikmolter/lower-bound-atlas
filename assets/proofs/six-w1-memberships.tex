The existence of a deterministic fixed-parameter algorithm for a problem
in \(\mathrm{W}[1]\) follows from \(\mathrm{FPT}=\mathrm{W}[1]\).
We give membership proofs for six explicit input models. Together
with the respective hardness results, these give equivalences for the
exclusion of deterministic fixed-parameter time. Throughout, the input
length includes the complete binary encoding.

\section{Grid Tiling}

\hypertarget{grid-tiling-w1-membership}{}
\begin{theorem}
Grid Tiling with equality on explicitly listed tables is in
\(\mathrm{W}[1]\) parameterized by the grid side \(k\).
\end{theorem}

\begin{proof}
The input lists one set of pairs from \([n]\times[n]\) for each
cell of a \(k\times k\) array. A solution chooses one pair per cell
with the first coordinate constant along each row and the second
coordinate constant along each column. Interchanging coordinates
gives the convention in~\cite[Theorem 14.28]{book}.

Construct a graph with one vertex for each listed option of each cell.
Use no edges between options of the same cell. Between options of
distinct cells, add an edge exactly when they agree on the first
coordinate if they share a row and on the second coordinate if
they share a column. A clique of size \(k^2\) takes one option
per cell, since a clique takes at most one from each cell.
The edges then certify all the required agreements.
Conversely, the options of a tiling form a clique of size \(k^2\).
The graph can be written in polynomial time by comparing explicitly
listed pairs. This argument does not enumerate the coordinate universe.
The requested clique size is a function of \(k\), so membership follows
from \(\mathrm{W}[1]\)-completeness of Clique, equivalently that of
Independent Set by complementation~\cite{df}.
\end{proof}

\section{Pairwise compatibility}

\hypertarget{unit-disk-independent-set-w1-membership}{}
\begin{theorem}
Independent Set of explicitly represented unit disks is in
\(\mathrm{W}[1]\) parameterized by the requested number of disks.
\end{theorem}

\hypertarget{unit-square-independent-set-w1-membership}{}
\begin{theorem}
Independent Set of explicitly represented axis-parallel unit squares
is in \(\mathrm{W}[1]\) parameterized by the requested number of squares.
\end{theorem}

\hypertarget{scattered-set-w1-membership}{}
\begin{theorem}
Scattered Set on unweighted undirected graphs is in \(\mathrm{W}[1]\)
parameterized by the requested number of vertices.
\end{theorem}

\hypertarget{planar-scattered-set-w1-membership}{}
\begin{theorem}
Scattered Set on unweighted planar graphs is in \(\mathrm{W}[1]\)
parameterized by the requested number of vertices.
\end{theorem}

\begin{proof}[Proofs of Theorems 2--5]
Make a graph on the available objects or vertices, with edges
between pairs allowed to appear together. A set of \(k\) mutually
compatible choices is exactly a clique of size \(k\).

For disks and squares, compatibility means disjointness of the closed
regions and can be tested in polynomial bit time on binary rational
coordinates. For unit-radius disks compare the squared distance
between centers with four. For axis-parallel unit squares inspect
the two pairs of coordinate intervals. These tests also work for
open regions after adjusting the boundary comparisons.

For Scattered Set, two distinct vertices are compatible when their
shortest-path distance is at least the input threshold \(d\).
Breadth-first searches determine all finite distances, and vertices in
different components have infinite distance. The tests are unchanged
on a planar input. The output graphs in all four reductions have
polynomial complete size, and the parameter is the same \(k\).
\end{proof}

\section{Weighted bounded-width CNF}

\hypertarget{weighted-q-cnf-w1-membership}{}
\begin{theorem}
For each fixed integer \(q\ge2\), satisfiability of an explicit CNF
with at most \(q\) literals per clause and exactly \(k\) true input
variables is in \(\mathrm{W}[1]\) parameterized by \(k\).
\end{theorem}

\begin{proof}
Make a circuit with the formula variables as its input variables.
Use a unary negation for each negative literal and build each clause's
disjunction using a tree of binary OR gates. Take their conjunction
with one output AND gate. Include the tautology \(x\lor\neg x\) as an
extra conjunct for each listed variable \(x\), so even unused variables
are inputs with paths to the output. Handle formulas with an empty
clause or no clauses directly. The circuit size is polynomial in the formula length
and its depth is at most \(2+\lceil\log_2 q\rceil\), fixed for the
given \(q\). Every input--output path contains at most one gate
of fan-in greater than two, the output conjunction. Thus the circuit has
weft at most one. Gate outputs add no input variables, so satisfying
assignments of weight exactly \(k\) correspond in both directions.
The result follows from the bounded-depth weft-one weighted circuit
definition of \(\mathrm{W}[1]\)~\cite[Definition 13.16]{book}.
\end{proof}

\section{Open and closed geometric regions}

The geometric reductions of Marx~\cite[Theorems 1 and 3]{marx}
use open squares and disks. We transfer these instances to the closed
regions used in the atlas.

\hypertarget{open-to-closed-regions}{}
\begin{theorem}
For lists of open unit disks or open axis-parallel unit squares with
binary rational coordinates, there is a polynomial-time transformation
to lists of closed regions of the same shape and size that preserves
the intersection graph, the number of regions, and the selection budget.
\end{theorem}

\begin{proof}
Represent each region by its center. For squares given by a corner,
adding half of the side length to each coordinate gives the center.
For a pair of disks, let its ratio be the squared Euclidean distance
between their centers divided by the squared diameter. For a pair of
squares, use the maximum absolute coordinate difference divided by
the side length. In either case a pair of open regions intersects
exactly when its ratio is less than one. The corresponding closed
regions intersect when the ratio is at most one.

Let \(r<1\) be the maximum ratio of an intersecting pair of open
regions, or zero if there is no such pair. Multiply every center
coordinate by \(\lambda=(3-r)/2>1\), keeping the sizes fixed.
For a pair of disks this multiplies its ratio by \(\lambda^2\).
For a pair of squares it multiplies its ratio by \(\lambda\).
Since
\[
  \lambda^2r-1=\frac{(r-1)^2(r-4)}{4}<0,
\]
and \(\lambda r\le\lambda^2r\), intersecting pairs continue to
intersect. Every originally disjoint pair had ratio at least one
and now has ratio strictly greater than one. Enumerating the pairs
and finding \(r\) takes polynomial time with exact rational
arithmetic. Each ratio, the scale factor, and each new coordinate use
a constant number of arithmetic operations on the original rationals,
so their bit lengths are polynomial in the input length.
\end{proof}
