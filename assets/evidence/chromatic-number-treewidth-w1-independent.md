# Independent agent review of the effective treewidth lower bound for Chromatic Number

**Verdict.** Theorem 1 (`tw-w1`) passes for deterministic Chromatic Number with a variable color budget, intrinsic treewidth, and a fixed polynomial in the complete input length. I checked the [complete source](../proofs/chromatic-number-treewidth-w1.tex) without participating in its construction.

**Reviewed source SHA-256, UTF-8 with LF line endings.** `1f54ebe9c862f2c3e42818775cd92645558501908f2a753ad467eb5ed6be6075`

The bits encode a tuple of valid vertex names. The cross-block clauses exclude every ordered equality or nonedge, so satisfying assignments select distinct adjacent vertices. After grouping the bits, the palette names all colors. For fixed group assignments, a selector can choose a group as its witness precisely when that group satisfies a literal. For every other group assignment, a private two-color vertex forbids that simultaneous choice of selector and assignment. Disjoint color sets enforce the orientation of the pair, and independence makes each allowed choice extend simultaneously to all private vertices.

I checked the bags and all size estimates. Each clause’s selector and each of its private tests occur together and meet the permanent palette and group vertices in the same bag. The maximum bag size is at most (q+2p+2). Every vertex has a contiguous interval. The number of tests and the explicit lists of edges per test are polynomial in the explicitly encoded Clique input with a constant degree independent of the requested clique size. In particular the intrinsic treewidth (t) satisfies t log₂(max(t, 2)) ≤ Ak ⌈log₂ n⌉ for a fixed integer (A). Computing treewidth is unnecessary.

The argument allows a finite, nonmonotone exponent with the stated computable thresholds. With (j=Ak), every width above threshold gives an exponent at most ⌈log₂ n⌉. For the remaining widths the threshold for (j=1) gives a global computable envelope after absorbing a finite prefix into one absolute constant. Evaluating that envelope up to (T(Ak)) yields a computable function of (k). Thus the assumed solver would place Clique in deterministic FPT. Clique hardness is the sole imported complexity result, by complementation from [Downey and Fellows, Independent Set](https://doi.org/10.1016/0304-3975(94)00097-3). The conclusion concerns effective convergence and does not establish an unrestricted little-o exclusion.
