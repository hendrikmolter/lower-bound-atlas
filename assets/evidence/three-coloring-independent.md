# Independent agent review of the 3-Coloring bounds

- In the forward map the common variable lets one interpret every satisfying NAE assignment with its value false by globally complementing all Boolean variables. For the splitting step I checked both cases of equality and inequality of the first two literals. Each clause uses a separate auxiliary variable. Literal vertices take opposite truth colors against the base triangle, and a clause triangle extends precisely on mixed truth colors. This also works with repeated literal occurrences. The count is $2v+8m+5$ vertices after normalization and the binary output is polynomial in the full formula input.
- The reverse map enforces exactly one color with four clauses per vertex and forbids each shared color with three clauses per edge. There are $3N$ variables even for a dense graph. Explicitly represented vertices and canonical names make construction and binary output length polynomial in the full graph input.
- Ordinary sparsification followed by the forward map makes the graph rate witness independent of the target solver and its fixed polynomial degree. For the converse, a separate SAT algorithm at rate $\delta/6$ for each fixed $\delta>0$ yields a graph algorithm at rate at most $\delta$. I checked that the equivalence concerns the common positive-rate exclusions. The older unrestricted little-o exclusion follows by domination and its converse remains open here.
- The forward SH implication handles empty clauses and conjunctions directly. The OR-tree encoding is equisatisfiable and uses a linear number of gates and auxiliary variables in the combinatorial CNF length. In the reverse implication, a failed-SH exponent $b$ and sufficiently small fixed $d>0$ give both $1-d<1$ and $b(1+Kd)<1$. Branch generation and solution therefore incur a fixed power below one in the variable count. The reverse graph encoding preserves that power up to the constant factor in $3N$. Normalization deals with binary names, and the possible logarithmic overhead allows an increase within the whole fixed-power family.
