# Source audit for Independent Set by rank-width and linear rank-width

The audit covers intrinsic rank-width, intrinsic linear rank-width, the actual width of a supplied rank decomposition, and the actual width of a supplied vertex order for the general-graph decision problem. The polynomial factor is in the complete binary input length, including any certificate.

## FPT ≠ W[1]

Theorem 2 states the effective quadratic-width exclusion by intrinsic linear rank-width. The proof constructs a vertex order in Lemma 3, after the false-twin expansion removes weights, with maximum prefix cut rank at most \(3d+4\) for \(d=\lceil\sqrt{m_{\mathrm{var}}}\rceil\). Thus it can be supplied directly. Placing the vertices as leaves along a caterpillar gives a rank decomposition, with width at most the maximum of one and the prefix width. This also bounds intrinsic rank-width. These constructions cost time polynomial in the explicit output length. In each interface the squared width is \(O(k\log n+1)\) for a source Clique instance on \(n\) vertices with requested size \(k\), so the same deterministic effective cutoff argument in Lemma 1 applies. Its exponent convention includes computable nonnegative integer exponents with computable cutoffs. [Molter, arXiv:2611.26080v2, Theorem 2, Lemma 1 and Sections 5.1–5.3](https://arxiv.org/html/2611.26080v2)

## SH

Table 1 and footnote e of the SH paper directly state the fixed-power exclusion by intrinsic rank-width. For the other interfaces, apply the SH exponent transfer to the Bergougnoux–Korhonen–Nederlof construction on a 3-CNF formula with \(s\) variables plus clauses. Section 4, including Lemmas 4.10 and 4.12, constructs the unweighted graph and the order in \(2^{O(\sqrt{s})}\) time times a polynomial in the normalized formula length, with width \(O(\sqrt{s})\). Supply the order from Lemma 4.12 directly, or place the leaves in that order along a caterpillar for the supplied rank decomposition. The source bit length after normalization is polynomial in \(s\). Hence Theorem 3.1 applies with parameter blowup exponent \(b=1/2\). For every fixed \(0<\epsilon<2\), the composition takes \(2^{O(s^{1-\gamma})}\) time for \(\gamma=\min\{1/2,\epsilon/2\}>0\), contradicting the size convention in Lemma 2.1. [Bergougnoux, Korhonen and Nederlof, STACS 2023, Section 4](https://doi.org/10.4230/LIPIcs.STACS.2023.11) · [MIT Hardness Group et al., arXiv:2611.02650v2, Lemma 2.1, Theorem 3.1 and Table 1](https://arxiv.org/pdf/2611.02650v2)
