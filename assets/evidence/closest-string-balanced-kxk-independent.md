# Independent verification of the balanced Closest String lower bound

Reviewed by Codex agent clique_batch on 18 November 2026. The reviewed source is [the LaTeX manuscript](../proofs/closest-string-balanced-kxk.tex), revision 1, with SHA-256 `0a30765d590e30160fe5c774b6be5a37fbc94d456530cf463dc7ed42cc17c504`. The forward implication is verified for deterministic decision, using complete binary input length $N$, radius $d$, common input string length $L=d+1$, and exactly $q=2d+3$ symbols appearing in the supplied strings. The conclusion is the exclusion of time $2^{o(d\log_2 d)}N^{O(1)}$ under the deterministic $k\times k$ Clique Hypothesis.

The first step imports the deterministic coloring family in Corollary 2.6 and Lemma 2.8 of Lokshtanov, Marx, and Saurabh. The number of query graphs and explicit production time are $2^{O(k\log\log k)}$ up to polynomial factors in $k$. The later steps use the constructions of Theorems 2.11, 2.12, and 3.1. Complementing each query graph preserves the row and column restrictions. In the two diagonal blocks, the mismatched copies of any row choice conflict, while the copies of each original edge conflict. Row sets force a column transversal to use one choice per row inside the two diagonal blocks, so the remaining sets test precisely the cross-block conflicts. [Lokshtanov, Marx, and Saurabh, author copy](https://sites.cs.ucsb.edu/~daniello/papers/slightlySuperexpSICOMP18.pdf)

For a fixed dummy missing from the center, agreement with a string using that dummy certifies a genuine selected cell for the corresponding set. Any input-alphabet dummy position can then be filled arbitrarily in the selection. A center symbol outside the input alphabet may also be replaced arbitrarily because it contributes no matches. Every row symbol occurs in the strings for its own row set, and each such string has dummy occurrences outside that row's diagonal block. Thus the stated alphabet size holds for every query, including no-instances. Each query has polynomial encoding size in $k$ and the substitution $d=2k-1$ preserves the stated little-o scale. The subexponential query overhead fits the same total clock. No objection remains within the forward implication.
