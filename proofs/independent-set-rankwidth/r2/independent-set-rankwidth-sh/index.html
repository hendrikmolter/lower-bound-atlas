A fixed-power lower bound for Independent Set on triangle-free graphs under SH

Theorem 1·A1 · A fixed-power lower bound for Independent Set on triangle-free graphs under SH

Exact theorem statement

Assuming deterministic SH, for every fixed 0<ε<20<ε<2 there is no deterministic 2𝒪(p2−ε)⁢N𝒪(1)2^(O(p^(2−ε))) N^(O(1)) Independent Set algorithm on triangle-free graphs by either intrinsic width, with or without an optimal corresponding certificate.
