An effective treewidth lower bound for Chromatic Number

Theorem 1 · tw-w1

Under deterministic FPT ≠ W[1], there is no Chromatic Number algorithm in 2^{h(t)h(t)} NCN^C for a fixed C and a finite nonnegative h effectively little-o of t⁢log2(max(t,2))t log₂(max(t,2)).
