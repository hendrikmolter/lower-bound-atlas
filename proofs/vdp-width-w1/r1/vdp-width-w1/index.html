Theorem 1 · Vertex-Disjoint Paths at optimal width on subcubic bipartite graphs

Exact theorem statement

Under deterministic FPT ≠ W[1], there is no correct deterministic Vertex-Disjoint Paths solver in 2^{h(w)h(w)} BCB^C time for a fixed C and a finite nonnegative h effectively little-o of max(1,w⁢log2(max(2,w)))max(1, w log₂(max(2,w))). The parameter is intrinsic treewidth or the width of a supplied path decomposition. The hard instances are connected bipartite graphs of maximum degree three with distinct leaf demand endpoints and equal treewidth and pathwidth. The supplied path decomposition is optimal.
