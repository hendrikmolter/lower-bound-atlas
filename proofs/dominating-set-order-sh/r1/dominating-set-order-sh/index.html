Theorem 1 · Dominating Set by number of vertices is equivalent to the Satisfiability Hypothesis

Exact theorem statement

SH is equivalent to the following exclusion: for every fixed 0<ε<10 < ε < 1, no deterministic Dominating Set algorithm runs in 2𝒪(n1−ε)⁢B𝒪(1)2^(O(n^(1−ε))) B^(O(1)) time, where n counts vertices and B is the complete binary input length.
