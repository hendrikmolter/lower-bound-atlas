A square-clique lower bound for Closest String with a balanced alphabet

Theorem 1·A1 · A square-clique lower bound for Closest String with a balanced alphabet

Exact theorem statement

Under the k×kk × k Clique Hypothesis, no deterministic Closest String algorithm runs in 2o(d⁢log2⁢d)⁢N𝒪(1)2^(o(d log₂ d)) N^(O(1)) time on instances of common length d+1d+1 with exactly 2⁢d+32d+3 distinct symbols occurring in the input strings.
