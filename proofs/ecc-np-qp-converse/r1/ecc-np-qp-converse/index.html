A converse for the Edge Clique Cover bound under NP ⊈ QP

Theorem 1·A1 · A converse for the Edge Clique Cover bound under NP ⊈ QP

Exact theorem statement

If Edge Clique Cover has no deterministic algorithm running in time 2k𝒪(1)⁢n𝒪(1)2^(k^(O(1))) n^(O(1)), then NP ⊈ QP.
