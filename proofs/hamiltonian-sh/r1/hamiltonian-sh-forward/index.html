Theorem 1 · Fixed-power lower bounds for Hamiltonian Cycle, Hamiltonian Path, and Longest Path

Exact theorem statement

Under SH, for every fixed 0<a<10 < a < 1, no deterministic algorithm runs in 2𝒪(pa)⁢B𝒪(1)2^(O(p^a)) B^(O(1)) time for Hamiltonian Cycle by vertices or vertices plus edges, Hamiltonian Path by vertices, or Longest Path by the requested path length.
