Theorem 1 · An effective treewidth lower bound for Dominating Set

Exact theorem statement

Under FPT ≠ W[1], no deterministic algorithm decides Dominating Set within the stated running time. f(k)⁢2oeff(t)⁢B𝒪(1)f(k) 2^(o_eff(t)) B^(O(1)). The graph is connected and bipartite. The prefactor f is any total computable positive integer-valued function of the solution budget k. The exponent h is computable and nonnegative integer-valued. There is a computable function T such that h(t)≤η⁢max(t,1)h(t) ≤ η max(t, 1) whenever t≥T(η)t ≥ T(η), for each positive rational η.
