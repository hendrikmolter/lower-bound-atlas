Theorem 1 · ilp-equations-w1-effective

Assuming deterministic FPT ≠ W[1], for every fixed C≥0C ≥ 0 and every finite nonnegative function h admitting a computable threshold T(j)T(j) with h(k)≤k/jh(k) ≤ k/j for every positive integer j and all k≥T(j)k ≥ T(j), no deterministic algorithm decides feasibility of Ax=1 over nonnegative integers for a binary k-row matrix A in 𝒪(2h(k)⁢NC)O(2^(h(k)) N^C) time, with complete binary input length N and unrestricted column count. The exclusion holds even when all columns are nonzero, in which case every feasible coordinate is at most one.
