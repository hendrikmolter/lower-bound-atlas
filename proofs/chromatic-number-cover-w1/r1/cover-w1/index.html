Theorem 1·A1 · A single-exponential lower bound for Chromatic Number by vertex cover number

Exact theorem statement

Under deterministic FPT ≠ W[1], there is no Chromatic Number algorithm in 2^{𝒪(k)O(k)} N^{𝒪(1)O(1)} for vertex cover number k.
