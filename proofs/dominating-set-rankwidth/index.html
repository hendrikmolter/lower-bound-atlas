Theorem 1 · dominating-set-rankwidth

Assuming deterministic FPT ≠ W[1], there is no deterministic effective 2^(o(p²)) N𝒪(1)N^(O(1)) Dominating Set algorithm on monopolar graphs by rank-width, linear rank-width, or the actual width of a supplied rank decomposition or vertex order.
