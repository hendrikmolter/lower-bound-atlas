Steiner Tree

Recorded parameterizationsNumber of terminals
Input
A finite simple undirected graph G with a set T of distinct terminals and a nonnegative integer edge budget b in binary.
Parameter
The number k of distinct vertices in the terminal set T.
Question
Does G have a tree spanning all terminals in T that uses at most b edges?
Input restrictions
  • The graph is finite, simple, undirected and unweighted.
