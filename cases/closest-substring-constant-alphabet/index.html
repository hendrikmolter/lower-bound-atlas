Constant-alphabet Closest Substring

Recorded parameterizationsDistance threshold and string count
Input
A collection of r strings over a fixed finite alphabet, a requested substring length, and an integer distance threshold d.
Parameter
The Hamming-distance threshold d and The number of input strings r.
Question
Is there a string of the requested length whose Hamming distance from some substring of each input string is at most d?
