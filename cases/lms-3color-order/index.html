3-Coloring

Recorded parameterizationsNumber of vertices
Input
A graph G.
Parameter
The number of vertices n = |V(G)V(G)|.
Question
Can the vertices of G be colored with at most three colors so that adjacent vertices have different colors?
Problem domain
  • The graph is finite, simple, undirected, and unweighted.

Restriction of

  • Chromatic Number (color budget ℓ = 3)

Restricted problems

  • Planar 3-Coloring (G is planar)
