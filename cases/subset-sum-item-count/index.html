Subset Sum

Recorded parameterizationsNumber of items
Input
An explicitly listed sequence of p positive binary integers and a positive binary target T.
Parameter
The number p of indexed input items.
Question
Does a subset of the item indices have values summing to T?
Input restrictions
  • Each item and the target is strictly positive. Equal item values may occur at different indices.
