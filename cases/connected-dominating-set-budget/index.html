Connected Dominating Set

Recorded parameterizationsSolution budget
Input
A finite simple undirected graph G and a nonnegative integer budget k.
Parameter
The solution budget k.
Question
Does G have a set of at most k vertices inducing a connected subgraph such that every vertex is in the set or has a neighbor in it?
