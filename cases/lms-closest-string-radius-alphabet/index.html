Closest String

Recorded parameterizationsRadius d Radius d and used alphabet size q
Input
A list of strings and a Hamming radius d.
Parameter
The radius d and the number q of distinct symbols occurring in the strings.
Question
Is there a string of length L at Hamming distance at most d from every input string?
Problem domain
  • All input strings have the same length L.

Superseding bound. An algorithm on unrestricted inputs at exponent scale d⁢log2⁢qd log₂ q would work on the promised slice at scale d⁢log2⁢dd log₂ d, since q=2⁢d+3q=2d+3 there. The exclusion on the slice therefore implies the unrestricted exclusion with its polynomial factor unchanged.
