Weighted normalized circuit satisfiability

Recorded parameterizationsAssignment weight at fixed depth
Input
A circuit and an integer k.
Parameter
The required assignment weight k.
Question
Decide whether exactly k input variables can be set to true to satisfy the circuit.
Input restrictions
  • The circuit has depth t. Unbounded-fan-in AND and OR gates alternate, the output gate is AND, and the inputs are literals.
