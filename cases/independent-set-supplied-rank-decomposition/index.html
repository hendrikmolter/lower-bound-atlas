Independent Set

Recorded parameterizationsLinear rank-width Number of vertices Rank-width Solution size Treewidth Width of a supplied rank decomposition Width of a supplied vertex order
Input
A finite, simple, undirected, unweighted graph G and a nonnegative integer k. A rank decomposition of G.
Parameter
The actual width of the supplied rank decomposition, denoted by p. Cut rank is computed over the binary field.
Question
Does G have at least k pairwise nonadjacent vertices?

Lower bounds by hypothesis

Notation

  • n — number of vertices of G
  • N — complete binary input length, including a supplied certificate if present
  • ε — fixed positive exponent saving
