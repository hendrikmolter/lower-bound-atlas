Planar Vertex Cover

Recorded parameterizationsNumber of vertices Solution size
Input
A finite, simple, undirected, unweighted graph G that is planar and a nonnegative integer k.
Parameter
The input threshold k.
Question
Does G have a set of at most k vertices that includes an endpoint of every edge?
Input restrictions
  • The graph is finite, simple, undirected, and unweighted.
  • The graph is planar.

  • Vertex Cover (G is planar)
