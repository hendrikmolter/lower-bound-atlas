Dominating Set

Recorded parameterizationsLinear rank-width Number of vertices Rank-width Solution size Treewidth Width of a supplied rank decomposition Width of a supplied vertex order
Input
A finite, simple, undirected, unweighted graph G and a nonnegative integer k.
Parameter
The rank-width of G, denoted by p. Cut rank is computed over the binary field.
Question
Does G have a set of at most k vertices such that every vertex either belongs to the set or has a neighbor in the set?

Restricted problems

  • Planar Dominating Set (G is planar)

Lower bounds by hypothesis

Notation

  • n — number of vertices of G
  • N — complete binary input length, including a supplied certificate if present
  • ε — fixed positive exponent saving

ETH (historical)

Subexponential bound in squared width

Input restrictions
  • The graph is monopolar, meaning that its vertices can be partitioned into an independent set and an induced disjoint union of cliques.
