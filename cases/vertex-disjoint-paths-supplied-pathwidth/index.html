Vertex-Disjoint Paths

Recorded parameterizationsTreewidth Width of a supplied path decomposition
Input
A finite simple undirected graph G and an explicit list of demand pairs of vertices. A path decomposition of G is supplied.
Parameter
The width p of the supplied path decomposition.
Question
Is there one path joining the endpoints of each demand pair, with all the paths pairwise vertex-disjoint?

Input restrictions
  • The graph is connected and bipartite, and its maximum degree is at most three.
  • All demand endpoints are distinct leaves.
  • The treewidth and pathwidth of G are equal.
  • The supplied path decomposition is optimal.
