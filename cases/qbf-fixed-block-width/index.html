Quantified Boolean satisfiability

Recorded parameterizationsPrimal treewidth at fixed quantifier depth
Input
A closed prenex Boolean formula with q alternating quantifier blocks, for a fixed q≥1q≥1.
Parameter
The treewidth t of the primal graph. Its vertices are the variables, and two variables are adjacent if they occur together in a clause or term.
Question
Is the quantified formula true?
Input restrictions
  • The matrix is in 3-CNF if the last quantifier is existential and in 3-DNF if it is universal.
