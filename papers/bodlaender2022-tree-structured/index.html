Recorded uses

  • Dominating Set · Proof of Corollary 12, p. 6:14. Apply the red-blue construction to the incidence graph, with sets blue. A hub adjacent to all sets and a private leaf increase the budget by one. After rejecting uncovered elements, the graph is connected and bipartite. The universe together with the hub is a vertex cover, so treewidth is at most the universe size plus one. Effective sublinearity then absorbs the treewidth exponent into an FPT running time for Clique. · Treewidth (Full bound · reduction to Dominating Set)
  • Independent Set · Theorem 11, Independent Set parameterized by logarithmic treewidth. The supplied tree decomposition can be discarded for the unrestricted problem. · Treewidth (unrestricted lower bound)
