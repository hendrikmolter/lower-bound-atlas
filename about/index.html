Using the atlas

Start with a problem and choose a parameterization. On each hypothesis card, read the excluded running time together with its input restrictions and quantifiers. Open “Full statement” for the precise claim, the original paper and, for an atlas-derived result, the proof.

To find out what survives under another hypothesis, select that hypothesis and a recovery status in the problem list. Each match identifies the historical ETH bound being compared. When citing a result, cite its original paper or proof. The statement’s revision permalink identifies the exact atlas entry you consulted.

Working with agents

Give your agent the JSON export to explore the current edition. To prepare a contribution, give it a clone of the repository with the agent README.

Look up a result

You can paste this example prompt into your agent.

Find the Distinct Vectors lower bound under FPT ≠ W[1]. Give the parameter, the excluded running time, and the range of its coefficient. Identify the historical ETH bound it recovers. Link to the original paper and the atlas proof.

Propose an entry

To let your agent choose a result, use this prompt.

Read AGENTS.md first. Propose one missing published lower bound for the atlas and show me the changes for review.

If you already have a result in mind, replace the bracketed text below.

Read AGENTS.md first. Add the [hypothesis] lower bound for [problem] parameterized by [parameter], from [paper link or DOI, theorem number]. Show me the proposed changes for review.

How to contribute

  1. Search the atlas for the problem, parameterization and hypothesis. If the bound is missing or needs a correction, identify the precise statement and its source, preferably a DOI and theorem number.
  2. Prepare the entry on a branch in your copy of the repository. External contributors can use a GitHub fork. Credit the contributor in the version history and run the atlas checks. For a new derivation, include the proof PDF and LaTeX source and obtain an independent correctness review.
  3. Open a pull request against main. The maintainer reviews the proposal and merges accepted changes. Entries selected for publication appear when the website is next built and published.

The contribution guide on GitHub includes the commands and a worked example. To suggest an entry or report a correction without preparing an edit, open a GitHub issue with the statement and source.

Scientific background

Many published running-time lower bounds rely on the Exponential Time Hypothesis (ETH). In October 2026, OpenAI and Anthropic each reported a deterministic subexponential-time algorithm for 3-SAT. Either result, if correct, would refute ETH. The atlas asks which historical lower bounds can be recovered under another hypothesis. ETH formulations and the reported refutations.

Recovery is assessed for a particular running time and input class. Sometimes another hypothesis yields the full exclusion; sometimes it yields a weaker exponent or requires effective convergence. When a bound itself implies ETH, an exact recovery would also prove ETH from the alternative hypothesis. Browse the hypotheses.

Creation and maintenance

Hendrik Molter (Hasso Plattner Institute, Potsdam) created the atlas and is currently its sole maintainer. It grew out of a research collection of published lower bounds, reductions and proof notes. ChatGPT agents assisted with source checks, proof drafting and independent reviews, and with building the database and website.

Disclaimer on correctness and attribution

Hendrik Molter assumes no responsibility as maintainer for the accuracy of the atlas, including its mathematical statements, proofs, citations and attributions. He takes responsibility for a proof only when he is listed as one of its authors.

Some proofs have been checked only by AI agents. On each proof page, the “Verification” section identifies the reviews on record. “Agent verified” means an AI agent checked the proof. Human review and formal verification in Lean are indicated separately when recorded. Browse the review records.

Please cite the original paper or proof for each mathematical result. If you found it through the Atlas, citing the Atlas as well is optional. To cite a specific entry, use the statement’s revision permalink.

If you reproduce or adapt Atlas content, credit Lower Bound Atlas and any named authors or contributors, link to the source and license, and indicate any changes. Licensing and attribution notice.
