Planar Strongly Connected Steiner Subgraph

Recorded parameterizationsNumber of terminals
Input
An explicitly encoded directed graph G whose underlying undirected graph is planar, with nonnegative integer arc weights, a specified terminal set of size k, and a nonnegative threshold.
Parameter
The number of terminals k.
Question
Is there a strongly connected subgraph containing the terminals whose total arc weight is at most the threshold?
