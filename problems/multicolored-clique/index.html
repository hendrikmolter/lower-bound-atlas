Multicolored Clique

Recorded parameterizationsNumber of color classes
Input
A finite simple undirected graph G and a partition of its vertices into k color classes.
Parameter
The number of color classes k.
Question
Is there a clique containing exactly one vertex from each color class?
Problem domain
  • The graph is finite, simple, undirected, and unweighted.
