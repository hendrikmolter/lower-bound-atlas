Problems

Vertex-Disjoint Paths

Input
A finite simple undirected graph G and an explicit list of demand pairs of vertices.
Question
Is there one path joining the endpoints of each demand pair, with all the paths pairwise vertex-disjoint?

Recorded parameterizations

Treewidth

The intrinsic treewidth t of G.

Width of a supplied path decomposition

The width p of the supplied path decomposition.

A path decomposition of G is supplied.
