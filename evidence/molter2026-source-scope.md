# Source scope for Running-Time Lower Bounds under FPT ≠ W[1]

Codex source audit, 20 November 2026. The edition checked is [Hendrik Molter, arXiv:2611.26080v1](https://arxiv.org/html/2611.26080v1), dated 19 November 2026. Sections 2.1–2.2 specify deterministic algorithms, complete input length, and the computable cutoff for each prescribed exponent saving. The notation does not require the exponent itself to be computable. Some Atlas statements impose a computability or upper-envelope restriction on the exponent. Those instances of the running-time exclusion follow from the preprint’s formulation. The comparison below checks the direction from the stated hypothesis to the Atlas bound.

| Theorem | Scope and comparison |
| --- | --- |
| 1 | Chromatic Number has a variable color budget and the parameter is the minimum vertex cover size. The single-exponential exclusion is a logarithmic-scale recovery of the historical vertex-cover exponent. |
| 5 | The Independent Set exclusion at the squared-width scale applies to triangle-free graphs. The four Atlas bounds use intrinsic rank-width, intrinsic linear rank-width, the width of a supplied optimal rank decomposition, and the width of a supplied optimal vertex order. Sections 7.3–7.4 provide the optimal certificates. Their widths equal the corresponding intrinsic widths and their sizes are polynomial in graph order. |
| 7 | The Distinct Vectors task uses an explicit binary matrix with distinct rows. The excluded double-exponential family allows each fixed coefficient strictly between zero and one in the inner exponent, covering the smaller coefficients in the ETH benchmark. |
| 8 | Integer Programming Feasibility uses a binary matrix and an all-ones right-hand side. The nonzero-column restriction is explicit, and the column count is unrestricted. The linear scale recovers the historical binary-coefficient theorem up to a logarithmic factor because a solver for general right-hand sides must also solve the all-ones instances. |
| 9 | Both Vertex-Disjoint Paths interfaces use the same effective width-times-logarithm scale. The graph is connected, bipartite and subcubic, with distinct leaf terminals and equal intrinsic widths. The supplied path decomposition is optimal. |
| 10 | The Cycle Packing theorem supports both intrinsic treewidth and supplied path-decomposition width. The connected bipartite hard inputs have maximum degree at most six, the stated girth for each fixed slack, and equal treewidth and pathwidth. Section 13.3 constructs the optimal supplied certificates. The effective exponent scale agrees with the historical scale for each interface. |
| 11 | Maximum Cycle Cover asks for a partition into at least the threshold number of simple cycles. The connected bipartite hard inputs have maximum degree at most eight. The supplied decomposition counts toward the complete input, and the effective width-times-logarithm scale agrees with the historical scale. |
| 12 | Line Distortion uses the shortest-path metric on connected simple unweighted bipartite graphs and the distortion threshold as parameter. Section 15 gives the same exclusion for real and integer noncontracting embeddings. Its exponent has the historical distortion-times-logarithm scale with a computable cutoff. |

Section 11 provides Lemma 5 on Permutation Hitting as a reduction ingredient for Theorems 9–12. The public Atlas has no separate Permutation Hitting bound.
