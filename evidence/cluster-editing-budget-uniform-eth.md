## Uniform ETH implies the bound

Normalize the full input in polynomial time, leaving length polynomial in the number \(v\) of occurring variables. For each positive integer \(j\), apply IPZ sparsification with tolerance \(1/j\). The \(2^{O(v/j)}\) branches have \(O_j(v)\) clauses and take \(2^{O(v/j)}\) time up to normalized polynomial factors. Decide branches with an empty clause or no clauses directly. Remove tautologies and duplicate literals. For every clause of width \(t<3\), add private new variables and replace it by its \(2^{3-t}\) sign completions. This is equisatisfiable and produces clauses on three distinct variables. For each occurring variable \(x\), append \((x\lor a_x\lor b_x)\) and \((\neg x\lor a_x\lor b_x)\) with private \(a_x,b_x\). Satisfiability is preserved and all variables now occur at least twice, so every variable cycle has length at least eight. Both padding steps retain a linear clause count.

For a padded branch with \(m\) clauses, the Komusiewicz–Uhlmann reduction gives a simple graph of maximum degree six on \(13m\) vertices with budget \(10m\). A \(2^{o(k)}n^{O(1)}\)-time solver gives a branch time of \(2^{o(v)}v^{O(1)}\) for fixed \(j\), using a monotone bound on the exponent if necessary. Interleave the corresponding correct solvers for all \(j\), giving every fixed \(j\) a fixed positive fraction of steps. Return the first answer. A fixed polynomial simulation overhead still gives an arbitrarily small linear coefficient in the exponent by considering a sufficiently large fixed \(j\). Thus one algorithm solves 3-SAT in \(2^{o(v)}L^{O(1)}\) time, where \(L\) is the original bit length. ## The bound implies uniform ETH

If uniform ETH fails, normalize each 3-CNF formula with \(m\) clauses to at most \(3m\) occurring variables and polynomial length in \(m\). The one variable-subexponential solver therefore gives a clause-subexponential solver. Use its nondecreasing time upper envelope \(T(m)=2^{o(m)}\) in Firbas–Sorge. The algorithm need not compute this upper envelope.

Accept immediately when the budget suffices to delete every edge. For \(k<8\), enumerate all sets of at most \(k\) edits in polynomial time. For the remaining budgets, run the transfer in round-robin for all integers \(2\le r\le\lfloor k^{1/3}\rfloor\), using the same 3-SAT solver, and return the first answer. Every run is correct. Each fixed \(r\) is eventually admissible and yields time \(2^{O(k\log(r)/r)}T(c_r k)n^{O(1)}\). Its linear exponent coefficient tends to zero as the fixed \(r\) grows, and \(T(c_r k)=2^{o(k)}\) for fixed \(r\). Simulation overhead is polynomial with fixed exponent and \(k\) is bounded by the number of edges. The combined clock is \(2^{o(k)}n^{O(1)}\) for one solver on general graphs, which includes the historical degree-six restriction.
