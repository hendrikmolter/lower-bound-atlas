# Independent agent review of the vertex cover bound for Chromatic Number

I checked both directions of the reduction. Every multicolored clique yields one sequence of bit-columns and one valid histogram guess. For a valid guess each pair of disjoint color banks uses two permutations; the ordered-pair tests force these permutations to agree at each position. Conversely the permutations specify a single name in each class, including possible padded names. Padding by isolated vertices preserves cliques of size at least two. For each nonedge of two classes, a cardinality mismatch in a block precludes this pair of names. When all cardinalities match, every candidate color of the nonedge test vertex is blocked exactly when the permuted position sets equal both sets of one-bit labels in every block. Thus its unavailable-color condition excludes precisely the forbidden pair. This includes the empty-set case. The test vertices have no mutual edges, so these individual extensions are simultaneous.

The palette and position vertices give a cover of size at most four times the padded bit length; no optimal cover is needed by the reduction. For h at least two, q = 2^h and b = 4q² satisfy q log₂(b+1) ≤ b, so all count vectors can be enumerated in at most 2^L trials before polynomial processing. With L < ceil(log₂ n)+b and at most a quadratic number of potential nonedges in the padded population, each query and the full enumeration have computable fixed-parameter overhead and constant polynomial exponent. For each proposed 2^{O(k)} solver its constant in the exponent is fixed independently of h; substituting k ≤ 4L leaves a fixed polynomial exponent of n even after all queries. This is a deterministic fixed-parameter Turing reduction, which suffices to contradict FPT ≠ W[1].

The imported premise is W[1]-completeness of parameterized Clique, also obtained from Independent Set by complementation. [Downey and Fellows, original paper](https://doi.org/10.1016/0304-3975(94)00097-3). This review certifies only the stated exclusion with its polynomial full-input factor. The argument recovers one logarithmic factor less in the exponent than the historical k log k benchmark.
