Independent Set by graph order under SH

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Independent Set within the stated running time.

2𝒪(n1−ε)⁢B𝒪(1)2^(O(n^(1−ε))) B^(O(1))

For each fixed ε strictly between zero and 1.

  • n — number of vertices
  • ε — a fixed positive saving in the exponent
  • B — complete input length in bits
