Independent Set by graph order under SH

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Independent Set within the stated running time.

2𝒪(n1−ε)⁢B𝒪(1)2^(O(n^(1−ε))) B^(O(1))

For each fixed ε strictly between zero and 1.

  • n — number of vertices
  • ε — a fixed positive saving in the exponent
  • B — complete input length in bits

Derivation from the cited sources

Use one Boolean selection variable per vertex and forbid selecting both ends of an edge. A linear-size cardinality circuit gives a 3-CNF with 𝒪(n)O(n) variables. A failure of SH would give a fixed-power 3-SAT algorithm by variable count.

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Exponential in the number of vertices

The SH bound excludes every fixed power below one in the exponent of the graph order n.
