Sublinear exponent in the full encoding length under ETH

Statement

No deterministic algorithm solves Weighted Fixed-Width CNF SAT within the stated running time.

f(k)⁢Mo(k)f(k) M^(o(k))

Separately for each fixed q≥2q ≥ 2. The source states the bound under the positive-rate SNP premise, which follows from ETH by sparsification.

The theorem also holds under k≤μ(M)k ≤ μ(M) for each nondecreasing unbounded function μ as in the source.

  • f — arbitrary total computable parameter function
  • k — required satisfying weight
  • M — complete source encoding length

ETH ⇒ Statement

  • Strong Computational Lower Bounds via Parameterized Complexity · Jianer Chen, Xiuzhen Huang, Iyad A. Kanj, Ge Xia · JCSS 72(8) (2006), 1346–1367 · Theorem 5.7, p. 1361
