Fixed-parameter tractability under FPT ≠ W[1]

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

No deterministic algorithm solves Weighted Fixed-Width CNF SAT within the stated running time.

f(k)⁢M𝒪(1)f(k) M^(O(1))

Separately for each fixed q≥2q ≥ 2.

  • f — arbitrary total computable parameter function
  • k — required satisfying weight
  • M — complete source encoding length
