Sublinear exponent in the candidate count under FPT ≠ W[1]

Statement

No deterministic algorithm solves Weighted CNF SAT within the stated running time.

f(k)⁢ro(k)⁢M𝒪(1)f(k) r^(o(k)) M^(O(1))

The theorem also holds under k≤μ(r)k ≤ μ(r) for each nondecreasing unbounded function μ as in the source.

  • f — arbitrary total computable parameter function
  • k — required satisfying weight
  • r — number of variables
  • M — complete source encoding length

FPT ≠ W[1] ⇒ Statement

  • Strong Computational Lower Bounds via Parameterized Complexity · Jianer Chen, Xiuzhen Huang, Iyad A. Kanj, Ge Xia · JCSS 72(8) (2006), 1346–1367 · Theorems 5.4 and 5.6, pp. 1359–1361
  • Tight Lower Bounds for Certain Parameterized NP-Hard Problems · Jianer Chen, Benny Chor, Mike Fellows, Xiuzhen Huang, David Juedes, Iyad A. Kanj, Ge Xia · Information and Computation 201(2) (2005), 216–231 · Theorem 3.5, pp. 225–227 (earlier bound without a parameter factor)
