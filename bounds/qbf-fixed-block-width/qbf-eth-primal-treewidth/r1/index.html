Problems / Quantified Boolean satisfiability

Tower bound at fixed quantifier depth under ETH

Statement

Input restrictions
  • The matrix is in 3-CNF if the last quantifier is existential and in 3-DNF if it is universal.

No deterministic algorithm decides Quantified Boolean satisfiability within the stated running time.

T(q,o(t))⁢n𝒪(1)T(q,o(t)) n^(O(1))

For each fixed integer q≥1q ≥ 1.

  • q — number of alternating quantifier blocks
  • t — treewidth of the primal graph
  • n — number of variables in the matrix
  • T(q,x)T(q,x) — a tower of q powers of two with x at the top, so T(1,x)=2xT(1,x)=2^x and T(2,x)=22xT(2,x)=2^(2^x)

The source treats the matrix as a set of clauses or terms and uses positive-rate variable-3SAT ETH. The polynomial factor counts the variables in the matrix.

ETH ⇒ Statement
