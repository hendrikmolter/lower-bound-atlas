Directed Steiner Tree under ETH: Subexponential-time bound

Statement

Input restrictions
  • The underlying undirected graph is planar.
  • Every arc has unit cost.

No deterministic algorithm solves the stated decision problem within the stated running time.

2o(p)⁢n𝒪(1)2^(o(p)) n^(O(1))

  • p — number of terminals other than the root
  • n — number of vertices

A rooted out-star demand counts one more vertex than the nonroot terminal set. The underlying unweighted Steiner Tree bound transfers by replacing each undirected edge by both unit-cost orientations.
