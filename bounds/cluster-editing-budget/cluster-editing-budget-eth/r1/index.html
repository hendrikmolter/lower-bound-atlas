Subexponential bound in the edit budget under ETH

Statement

Input restrictions
  • The input graph has maximum degree at most six.

No deterministic algorithm solves Cluster Editing within the stated running time.

2o(k)⁢n𝒪(1)2^(o(k)) n^(O(1))

  • k — maximum number of edge additions and deletions
  • n — number of vertices in the input graph
