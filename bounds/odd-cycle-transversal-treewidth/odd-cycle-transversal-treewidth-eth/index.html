Exponent in treewidth under ETH

Statement

No deterministic algorithm solves Odd Cycle Transversal within the stated running time.

2o(t)⁢n𝒪(1)2^(o(t)) n^(O(1))

  • t — treewidth of the input graph
  • n — number of vertices of the input graph

ETH ⇒ Statement
