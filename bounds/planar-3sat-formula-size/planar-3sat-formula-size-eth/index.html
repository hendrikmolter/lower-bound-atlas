Problems / Planar 3SAT

Exponent in number of variables plus clauses under ETH

Statement

No deterministic algorithm solves Planar 3SAT within the stated running time.

2o(s1/2)⁢B𝒪(1)2^(o(s^(1/2))) B^(O(1))

  • s — number of variables plus number of clauses
  • B — complete explicit binary input length

ETH ⇒ Statement
