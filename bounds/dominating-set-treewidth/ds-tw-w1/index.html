Effective little-o bound in the treewidth under FPT ≠ W[1]

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.
Input restrictions
  • The graph is connected and bipartite.

No deterministic algorithm decides Dominating Set within the stated running time.

f(k)⁢2oeff(t)⁢B𝒪(1)f(k) 2^(o_eff(t)) B^(O(1)) Effective little-o

The solution-budget factor f is any computable positive integer-valued function.

The exponent is a computable nonnegative integer-valued function.

  • f — a computable prefactor in the solution budget
  • k — solution threshold
  • t — treewidth of the input graph
  • B — complete input length in bits

FPT ≠ W[1] ⇒ Statement

  • Full bound · small-universe Set Cover · A Simple Gap-Producing Reduction for the Parameterized Set Cover Problem · Bingkai Lin · ICALP 2019, LIPIcs 132, 81:1–81:15 · Lemma 14, pp. 81:11–81:12. For clique size ℓ, the cover budget is ℓ(ℓ−1)/2 and the universe has size ℓ^O(1) log n. · Open full text
  • Full bound · reduction to Dominating Set · On the Complexity of Problems on Tree-Structured Graphs · Hans L. Bodlaender, Carla Groenland, Hugo Jacob, Marcin Pilipczuk, Michał Pilipczuk · IPEC 2022, LIPIcs 249, 6:1–6:17 · Proof of Corollary 12, p. 6:14. Apply the red-blue construction to the incidence graph, with sets blue. A hub adjacent to all sets and a private leaf increase the budget by one. After rejecting uncovered elements, the graph is connected and bipartite. The universe together with the hub is a vertex cover, so treewidth is at most the universe size plus one. Effective sublinearity then absorbs the treewidth exponent into an FPT running time for Clique.
  • Origin of the Set Cover construction · On the Parameterized Complexity of Approximating Dominating Set · Karthik C. S., Bundit Laekhanukit, Pasin Manurangsi · Journal of the ACM 66(5) (2019), Article 33 · Credited by Lin at the start of Section 3.4 for the idea behind Lemma 14.
  • Unrestricted graphs, no solution-budget prefactor · Parameterized problems complete for nondeterministic FPT time and logarithmic space · Hans L. Bodlaender, Carla Groenland, Jesper Nederlof, Céline M. F. Swennenhuis · Information and Computation 300 (2024), 105195 · Theorem 17 and Lemma 2. Hardness for logarithmic pathwidth implies the effective sublinear treewidth exclusion when f = 1.

Recovery of a historical ETH bound

Effectively recovered · ETH target: Exponential in the treewidth

Taking f=1f=1 reaches the historical treewidth exponent scale for computable effectively sublinear exponents. The exclusion holds on connected bipartite graphs and allows a computable prefactor in the solution budget.
