Effective little-o bound in the treewidth under FPT ≠ W[1]

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.
Input restrictions
  • The graph is connected and bipartite.

No deterministic algorithm decides Dominating Set within the stated running time.

The solution-budget factor f is any computable positive integer-valued function.

The exponent is a computable nonnegative integer-valued function.

  • f — a computable prefactor in the solution budget
  • k — solution threshold
  • t — treewidth of the input graph
  • B — complete input length in bits

Derivation from the cited sources

For a clique of size ℓ in an n-vertex graph, Lin gives a Set Cover instance with budget ℓ(ℓ−1)/2 and universe size at most g(ℓ) log₂ n for a computable g. Apply the construction of Bodlaender et al. to its incidence graph: join a new vertex to every set vertex and to a private leaf. After rejecting instances with an uncovered element, the graph is connected and bipartite, and its domination budget is k=ℓ(ℓ−1)/2+1. The universe vertices together with the new vertex form a vertex cover, so the treewidth is at most g(ℓ) log2⁢n+1log₂ n+1. Effective sublinearity therefore bounds the exponential factor by a computable function of ℓ times n, while f(k)f(k) depends only on ℓ. The claimed algorithm would thus decide Clique in fixed-parameter time.

Recovery of a historical ETH bound

Effectively recovered · ETH target: Exponential in the treewidth
