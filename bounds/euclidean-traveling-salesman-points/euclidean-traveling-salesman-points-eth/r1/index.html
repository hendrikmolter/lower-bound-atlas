Euclidean Traveling Salesman under ETH: Dimension-dependent subexponential bound

Statement

Input restrictions
  • The point coordinates are integers and T=nT=n.

No deterministic algorithm solves the stated decision problem within the stated running time.

2o(n1−1/d)⁢B𝒪(1)2^(o(n^(1−1/d))) B^(O(1))

Separately for each fixed integer d≥2d ≥ 2.

  • n — number of input points
  • d — the fixed dimension
  • B — complete explicit binary input length

ETH ⇒ Statement

  • A Framework for Exponential-Time-Hypothesis–Tight Algorithms and Lower Bounds in Geometric Intersection Graphs · Mark de Berg, Hans L. Bodlaender, Sándor Kisfaludi-Bak, Dániel Marx, Tom C. van der Zanden · SIAM Journal on Computing 49(6) (2020), pp. 1291–1331 · Corollary 4.8 via Theorem 4.7 · Open full text
Derivation from the cited sources

On the integer-grid instances a tour of length at most n exists exactly when the induced grid graph has a Hamiltonian cycle. This also excludes an exact optimal-tour algorithm.
