Effective little-o bound in the treewidth under FPT ≠ W[1]

Statement

No deterministic algorithm decides Red-Blue Dominating Set within the stated running time.

2oeff(t)⁢B𝒪(1)2^(o_eff(t)) B^(O(1)) Effective little-o

  • t — treewidth of the input graph
  • B — complete binary input length

FPT ≠ W[1] ⇒ Statement

  • On the Complexity of Problems on Tree-Structured Graphs · Hans L. Bodlaender, Carla Groenland, Hugo Jacob, Marcin Pilipczuk, Michał Pilipczuk · IPEC 2022, LIPIcs 249, 6:1–6:17 · §5.3, Theorem 11 and Corollary 12, pp. 6:13–6:14
Derivation from the cited sources

Logarithmic-treewidth Red-Blue Dominating Set is XALP-hard, so it is W[1]-hard. The edge-subdivision construction has an explicit blue/red partition. Discard the supplied decomposition. For a Clique input of order n and parameter k, the output treewidth is at most g(k)⁢(1+log2⁢n)g(k)(1+log₂ n) for a computable g. Use the computable cutoff for a slope at most 1/g(k)1/g(k). Above the cutoff the exponential factor is polynomial in n, and below it the computable exponent has a finite maximum controlled by k. The polynomial-size reduction output then gives an FPT algorithm for Clique.
