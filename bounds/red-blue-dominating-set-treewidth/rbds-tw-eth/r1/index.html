Problems / Red-Blue Dominating Set

Exponential dependence on treewidth under ETH

Statement

No deterministic algorithm decides Red-Blue Dominating Set within the stated running time.

2o(t)⁢B𝒪(1)2^(o(t)) B^(O(1))

  • t — treewidth of the input graph
  • B — complete binary input length

ETH ⇒ Statement

  • Which Problems Have Strongly Exponential Complexity? · Russell Impagliazzo, Ramamohan Paturi, Francis Zane · JCSS 63(4) (2001), 512–530 · Corollary 2, p. 524, and Theorem 5, p. 526 · Open full text
  • Lower bounds based on the Exponential Time Hypothesis · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · Bulletin of the EATCS 105 (2011), 41–71 · Theorem 3.3, p. 52 · Open full text
  • On the Complexity of Problems on Tree-Structured Graphs · Hans L. Bodlaender, Carla Groenland, Hugo Jacob, Marcin Pilipczuk, Michał Pilipczuk · IPEC 2022, LIPIcs 249, 6:1–6:17 · §5.3, Theorem 11 and Corollary 12, pp. 6:13–6:14
Derivation from the cited sources

Subdivide every edge of a Vertex Cover instance. The blue original vertices dominate the red subdivision vertices exactly when they cover all original edges. A single bag with all original vertices and an attached bag for each subdivision gives treewidth at most max(n−1,2)max(n−1, 2) for original order n. The new explicit encoding has polynomial size.
