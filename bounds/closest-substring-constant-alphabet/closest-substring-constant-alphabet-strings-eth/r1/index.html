Constant-alphabet Closest Substring under ETH: Double-logarithmic string-count exponent

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

f(d,r)⁢No(log2⁢log2⁢r)f(d,r) N^(o(log₂ log₂ r))

For every computable joint prefactor f.

  • d — Hamming-distance threshold
  • r — number of input strings
  • N — size of the string input in the source

ETH ⇒ Statement

  • Lower bounds based on the Exponential Time Hypothesis · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · Bulletin of the EATCS 105 (2011), 41–71 · Theorem 5.6, p. 60 · Open full text
