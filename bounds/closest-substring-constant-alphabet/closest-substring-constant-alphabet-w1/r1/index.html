Binary Closest Substring under FPT ≠ W[1]

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

Input restrictions
  • The alphabet is binary.

No deterministic algorithm solves binary Closest Substring within the stated running time.

f(d,r)⁢N𝒪(1)f(d,r) N^(O(1))

For every computable joint prefactor f.

  • d — Hamming-distance threshold
  • r — number of input strings
  • N — size of the string input in the source
