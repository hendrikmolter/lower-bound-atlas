Fixed-parameter tractability under FPT ≠ W[1]

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

No deterministic algorithm solves Grid Tiling within the stated running time.

f(k)⁢B𝒪(1)f(k) B^(O(1))

The parameter factor f is an arbitrary computable function.

  • k — side length of the grid
  • B — complete explicit binary input length
