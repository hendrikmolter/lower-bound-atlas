Effective quadratic-width bound on triangle-free graphs under FPT ≠ W[1]

Statement

Input restrictions
  • The input graph has no triangle.

No deterministic algorithm decides Independent Set within the stated running time.

2oeff(p2)⁢N𝒪(1)2^(o_eff(p^2)) N^(O(1))

The exponent is a computable nonnegative integer function and has computable convergence to little-o at scale p2p^2.

  • p — linear rank-width of G
  • N — complete binary input length, including a supplied certificate if present

The proof uses paths to replace selection cliques and a triangle-free padding graph to force optimal certificates.

Recovery of a historical ETH bound

Effectively recovered · ETH target: Subexponential bound in squared width

The recovered clock is the same squared-width scale with a computable exponent and modulus. The restricted instances are valid inputs of the historical task and the normalized full graph encoding, including any supplied certificate, is polynomial in its order.
