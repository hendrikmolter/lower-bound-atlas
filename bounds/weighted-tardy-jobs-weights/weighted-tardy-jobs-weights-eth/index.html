Problems / Weighted Number of Tardy Jobs on One Machine

Exponent sublinear in k/log⁢kk / log k under ETH

Statement

No deterministic algorithm solves Weighted Number of Tardy Jobs on One Machine within the stated running time.

no(k/log2⁢k)⁢N𝒪(1)n^(o(k / log₂ k)) N^(O(1))

  • k — number of distinct weights in the input
  • n — number of jobs
  • N — total bit length of the input

ETH ⇒ Statement

  • Minimizing the Weighted Number of Tardy Jobs is W[1]-hard · Klaus Heeger, Danny Hermelin · Journal of Computer and System Sciences 161 (2026), Article 103817 · Corollary 1, pp. 3 and 18, and §5
Derivation from the cited sources

The paper states its lower bound in the job count. On the constructed instances the scheduling numbers have polynomial bit length in the source graph size, so a fixed polynomial in the total bit length is absorbed by the source lower bound.
