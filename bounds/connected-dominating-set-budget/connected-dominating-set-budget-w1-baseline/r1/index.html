Connected Dominating Set under FPT ≠ W[1]: Fixed-parameter tractability

Statement

No lower bound recorded for this parameterization beyond W[2]-hardness.

No deterministic algorithm solves this decision problem within the stated running time.

f(k)⁢B𝒪(1)f(k) B^(O(1))

The parameter factor f is an arbitrary computable function and the exponent of B is an arbitrary fixed constant.

  • k — solution budget
  • B — complete binary input length

The reduction from Dominating Set preserves the solution budget. W[2]-hardness excludes fixed-parameter tractability under FPT ≠ W[1] because W[1] is contained in W[2].
