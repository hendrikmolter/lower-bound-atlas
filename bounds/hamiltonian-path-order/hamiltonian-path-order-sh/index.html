Fixed-power bounds under SH

Statement

No deterministic algorithm can decide Hamiltonian Path within the stated running time.

2𝒪(na)⁢B𝒪(1)2^(O(n^a)) B^(O(1))

Separately for every fixed 0<a<10 < a < 1.

  • n — number of vertices of the input graph
  • B — complete explicit binary input length

SH ⇒ Statement

Derivation from the cited sources

Choose a dimension for the desired exponent. Split one vertex of the Hamiltonian Cycle instance into two copies with the same neighbors and put a private leaf on each copy. The forced path endpoints give an equivalent Hamiltonian Path instance with only three more vertices.

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Exponent in number of vertices

The SH result excludes every fixed power below one in the exponent of the number of vertices.
