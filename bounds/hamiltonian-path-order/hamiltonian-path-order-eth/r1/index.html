Exponent in number of vertices under ETH

Statement

No deterministic algorithm solves Hamiltonian Path within the stated running time.

2o(n)⁢B𝒪(1)2^(o(n)) B^(O(1))

  • n — number of vertices of the input graph
  • B — complete explicit binary input length
