Subgraph Isomorphism under FPT ≠ W[1]: Fixed-parameter tractability

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

No deterministic algorithm solves this decision problem within the stated running time.

f(k)⁢B𝒪(1)f(k) B^(O(1))

The parameter factor f is an arbitrary computable function and the exponent of B is an arbitrary fixed constant.

  • k — number of pattern edges
  • B — complete binary input length

Use a complete graph on ℓ vertices as the pattern for a Clique instance with target ℓ. An injective edge-preserving image is an ℓ-clique, and the pattern has exactly ℓ(ℓ−1)/2 edges. Cases with ℓ greater than the host order can be answered directly.
