Problems / Subgraph Isomorphism

Exponent sublinear in the parameter divided by its logarithm under ETH

Statement

No deterministic algorithm solves Subgraph Isomorphism within the stated running time.

f(k)⁢no(k/log(k+2))f(k) n^(o(k/log(k+2)))

  • f — arbitrary total computable parameter function
  • k — number of pattern edges
  • n — number of vertices of host graph G
