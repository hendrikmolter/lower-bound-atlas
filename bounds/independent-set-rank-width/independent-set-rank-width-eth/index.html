Subexponential bound in squared width under ETH

Statement

No deterministic algorithm decides Independent Set within the stated running time.

2o(p2)⁢n𝒪(1)2^(o(p^2)) n^(O(1))

  • p — rank-width of G
  • n — number of vertices of G

The published theorem is stated by linear rank-width. Rank-width is at most linear rank-width, and taking a monotone upper envelope preserves the exponent scale.

ETH ⇒ Statement

  • Tight Lower Bounds for Problems Parameterized by Rank-Width · Benjamin Bergougnoux, Tuukka Korhonen, Jesper Nederlof · STACS 2023, LIPIcs 254, pp. 11:1–11:17 · Theorem 1.1, p. 11:2, and Theorem 4.11 and Lemma 4.12, pp. 11:10–11:11 · Open full text
