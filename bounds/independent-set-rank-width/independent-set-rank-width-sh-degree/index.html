Problems / Independent Set

Fixed-power bound below squared width on triangle-free graphs under SH

Statement

Input restrictions
  • The input graph has no triangle.

No deterministic algorithm decides Independent Set within the stated running time.

2𝒪(p2−ε)⁢N𝒪(1)2^(O(p^(2−ε))) N^(O(1))

For every fixed 0<ε<20<ε<2.

  • p — rank-width of G
  • ε — fixed positive exponent saving
  • N — complete binary input length, including a supplied certificate if present

Derivation from the cited sources

On a 3-CNF formula with s variables plus clauses, Molter’s reduction produces a triangle-free graph of width O(√s) in 2^{O(√s⁢log(s+2)s log(s+2))} time. Substituting the width bound gives a fixed power saving in the exponent for 3-SAT.

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Subexponential bound in squared width

For every fixed positive exponent saving below two, the recovery excludes the corresponding power of the same width. The restricted instances are valid inputs of the historical task and the normalized full graph encoding, including any supplied certificate, is polynomial in its order.
