Vertex Cover by solution size under SH

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Vertex Cover within the stated running time.

2𝒪(k1−ε)⁢B𝒪(1)2^(O(k^(1−ε))) B^(O(1))

For each fixed ε strictly between zero and 1.

  • k — solution threshold
  • ε — a fixed positive saving in the exponent
  • B — complete input length in bits

Derivation from the cited sources

First apply the polynomial-time 2k-vertex kernel. The vertex-cover cardinality encoding gives a 3-CNF with 𝒪(k)O(k) variables, so failure of SH would give a fixed-power algorithm by budget.

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Exponential in the solution budget

The SH bound excludes every fixed power below one in the exponent of the cover budget k.
