Effective quadratic-width bound on monopolar graphs under FPT ≠ W[1]

Statement

Input restrictions
  • The graph is monopolar, meaning that its vertices can be partitioned into an independent set and an induced disjoint union of cliques.

No deterministic algorithm decides Dominating Set within the stated running time.

2oeff(p2)⁢N𝒪(1)2^(o_eff(p^2)) N^(O(1)) Effective little-o

The exponent is a computable nonnegative integer-valued function.

  • p — linear rank-width of G
  • N — complete binary input length, including a supplied certificate if present

FPT ≠ W[1] ⇒ Statement

  • Lower Bounds for Domination-Type Problems Parameterized by Rank-Width · Chenghua Liu, Boning Meng · arXiv:2608.18854v1, 19 August 2026 · Section 3.2, Lemmas 3.5–3.6, and Appendix C, proof of Theorem C.1 · Open full text
Derivation from the cited sources

Encode the k vertices of a clique choice in 𝒪(k⁢log⁢n)O(k log n) Boolean variables, using clauses to forbid invalid vertices, repetitions and nonedges. Liu and Meng’s reduction then supplies a monopolar graph and a vertex order of width p with p² = 𝒪(k⁢log⁢n)O(k log n), in fixed-parameter time. The intrinsic width is at most the width of the order. The computable cutoff for the exponent converts any algorithm with the displayed running time into a fixed-parameter algorithm for Clique.

Recovery of a historical ETH bound

Effectively recovered · ETH target: Subexponential bound in squared width

Both bounds concern the same width interface and monopolar graphs. The W[1] recovery retains the quadratic scale with computable exponent and convergence. The explicit order and rank decomposition have polynomial length in graph order.
