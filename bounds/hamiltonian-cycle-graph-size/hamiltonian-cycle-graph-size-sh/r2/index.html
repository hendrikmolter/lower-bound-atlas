Fixed-power bounds under SH

Statement

No deterministic algorithm can decide Hamiltonian Cycle within the stated running time.

2𝒪(sa)⁢B𝒪(1)2^(O(s^a)) B^(O(1))

Separately for every fixed 0<a<10 < a < 1.

  • s — number of vertices plus number of edges of G
  • B — complete explicit binary input length

Equivalence to SH

SH ⇒ Statement

  • ETH is Dead, Long Live SH · MIT Hardness Group, Josh Brunner, Erik D. Demaine, Fabian Frei, Timothy Gomez, Markus Hecher, Jeffery Li, Jayson Lynch · arXiv:2611.02650v2, 16 November 2026 · Table 1, induced-grid row, p. 4 · Open full text
  • A Framework for Exponential-Time-Hypothesis–Tight Algorithms and Lower Bounds in Geometric Intersection Graphs · Mark de Berg, Hans L. Bodlaender, Sándor Kisfaludi-Bak, Dániel Marx, Tom C. van der Zanden · SIAM Journal on Computing 49(6) (2020), pp. 1291–1331 · Theorem 4.7 · Open full text
Derivation from the cited sources

Choose the dimension separately for each fixed power below one. The number of edges of a fixed-dimensional grid graph is at most its dimension times its number of vertices, so the same exclusion holds in graph size.

Statement ⇒ SH

  • Encoding the Hamiltonian Cycle Problem into SAT Based on Vertex Elimination · Neng-Fa Zhou · CP 2024, LIPIcs 307, pp. 40:1–40:8 · §2, pp. 40:2–40:3 · Open full text
Derivation from the cited sources

Replace every undirected edge by two opposite arcs. The degree constraints take linear size and the binary distance increment takes 𝒪(log⁢n)O(log n) gates per arc, giving a CNF of near-linear bit length in the graph size. A fixed power saving for SAT then gives a fixed power saving for Hamiltonian Cycle.

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Exponent in number of vertices plus edges

The SH result excludes every fixed power below one in the exponent of the number of vertices plus edges.
