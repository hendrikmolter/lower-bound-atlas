Exponent in number of vertices plus edges under ETH

Statement

No deterministic algorithm solves Hamiltonian Cycle within the stated running time.

2o(s)⁢B𝒪(1)2^(o(s)) B^(O(1))

  • s — number of vertices plus number of edges of G
  • B — complete explicit binary input length
