3SAT under the k×kk × k Clique Hypothesis: Square-root exponent with a logarithmic factor

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

2o(n1/2⁢log2⁢n)⁢B𝒪(1)2^(o(n^(1/2) log₂ n)) B^(O(1))

  • n — number of declared variables
  • B — complete explicit binary input length

The log factor multiplies the square root. The reduction encodes each row choice and incompatibility in a width-three formula with quadratically many variables.
