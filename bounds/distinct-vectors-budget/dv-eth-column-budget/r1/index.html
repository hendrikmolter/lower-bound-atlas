Double-exponential bound under ETH

Statement

Problem domain
  • The rows are pairwise distinct.

No deterministic algorithm decides Distinct Vectors within the stated running time.

2𝒪(2c⁢k)⁢(m+n)𝒪(1)2^(O(2^(c k))) (m+n)^(O(1))

For every fixed ε>0ε > 0, let c=1/2−εc = 1/2 − ε.

  • k — maximum number of selected columns
  • m — number of rows
  • n — number of columns
