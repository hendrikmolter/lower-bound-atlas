Effective double-exponential bound under FPT ≠ W[1]

Statement

Problem domain
  • The rows are pairwise distinct.

No deterministic algorithm decides Distinct Vectors within the stated running time.

  • k — maximum number of selected columns
  • N — input length in bits, including the binary column budget

FPT ≠ W[1] ⇒ Statement

  • A Simple Gap-Producing Reduction for the Parameterized Set Cover Problem · Bingkai Lin · ICALP 2019, LIPIcs 132, 81:1–81:15 · Lemma 14 and proof, §3.4, pp. 81:11–81:12 · Open full text
  • Combinatorial Feature Selection: Parameterized Algorithms and Complexity · Vincent Froese · Master’s thesis, Technische Universität Berlin, 2012 · Theorem 4.1 and proof, §4.1.1, pp. 33–34
Derivation from the cited sources

Lin’s Set Cover reduction has a universe of size O(h³ log n) and a budget depending only on h for an n-vertex Multicolored Clique instance with h colors. Froese’s binary address forces one column per address bit, and the two rows at each address must be separated by a selected set containing the corresponding element. The extra budget is the ceiling of the logarithm of the universe size, so 2k≤g(h)⁢(1+log⁢n)2^k ≤ g(h)(1+log n) for a computable g. Reject a universe element with no incident set before building the matrix. A computable cutoff for an exponent in oeff(2k)o_eff(2^k) gives a fixed-parameter algorithm for Multicolored Clique.

Recovery of a historical ETH bound

Recovered · ETH target: Double-exponential bound

For every historical coefficient c<1/2c < 1/2, 𝒪(2c⁢k)O(2^(c k)) has a computable convergence cutoff relative to 2k2^k. The effective exclusion therefore covers the historical running-time family on the same binary matrices.
