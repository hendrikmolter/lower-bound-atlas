Problems / Planar 3-Coloring

Square-root exponent on planar graphs under ETH

Statement

Input restrictions
  • The graph is finite, simple, undirected, and unweighted.
  • The graph is planar.

No deterministic algorithm decides Planar 3-Coloring within the stated running time.

2o(n1/2)⁢B𝒪(1)2^(o(n^(1/2))) B^(O(1))

  • n — number of vertices
  • B — input length in bits
