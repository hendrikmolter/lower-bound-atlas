Fixed-power bound on cubic bipartite line graphs under SH

Statement

Input restrictions
  • The input is the line graph of a connected simple cubic bipartite graph. The root graph need not be supplied.

No deterministic algorithm decides Feedback Vertex Set within the stated running time.

2𝒪(k1−ε)⁢N𝒪(1)2^(O(k^(1−ε))) N^(O(1))

For every fixed 0<ε<10<ε<1.

  • k — solution budget
  • ε — fixed positive exponent saving
  • N — complete binary input length, including a supplied certificate if present

SH ⇒ Statement

  • NP-Completeness of the Hamiltonian Cycle Problem for Bipartite Graphs · Takanori Akiyama, Takao Nishizeki, Nobuji Saito · Journal of Information Processing 3(2) (1980), 73–76 · Section 2 and Figures 1–5, pp. 73–75, before crossing replacement
  • On Line Graphs of Subcubic Triangle-Free Graphs · Andrea Munaro · Discrete Mathematics 340(6) (2017), 1210–1226 · Theorems 21, 23 and 24 and Figure 5 (open author copy, §5, pp. 13–15) · Open full text

Source note

The same construction keeps both the deletion budget and the sum of graph order and size linear in the variable-plus-clause count of the source formula.

Historical status

This bound follows by composing the cited reductions with the SH exponent transfer. The cubic bipartite graph before crossing replacement has linear size in the formula. The local path reduction adds a constant number of vertices, and the final line graph is four-regular with deletion budget one plus a third of its order.

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Subexponential-time bound

For every separately fixed positive saving below one, the SH bound excludes the corresponding power of the same parameter. The cubic bipartite line graphs are valid historical inputs, and their explicit encodings have polynomial size in the source formula.
