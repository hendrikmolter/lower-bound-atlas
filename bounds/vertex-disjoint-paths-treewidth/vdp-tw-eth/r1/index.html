Problems / Vertex-Disjoint Paths

Bound in the treewidth under ETH

Statement

No deterministic algorithm decides Vertex-Disjoint Paths within the stated running time.

2o(t⁢log2⁢t)⁢B𝒪(1)2^(o(t log₂ t)) B^(O(1))

  • t — treewidth of the input graph
  • B — the complete input length in bits, including all demand pairs

The sources use a polynomial factor in graph order. The reductions use explicit instances with distinct endpoints, so their demand lists and complete encodings have length polynomial in graph order.

ETH ⇒ Statement

  • Slightly Superexponential Parameterized Problems · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · SIAM J. Comput. 47(3) (2018), 675–702 · Section 5, Theorem 5.4, pp. 696–697
