Fixed-power bounds in the treewidth under SH

Statement

No deterministic algorithm decides Vertex-Disjoint Paths within the stated running time.

2𝒪(t1−ε)⁢B𝒪(1)2^(O(t^(1−ε))) B^(O(1))

For every fixed 0<ε<10 < ε < 1.

  • t — treewidth of the input graph
  • B — the complete input length in bits, including all demand pairs
