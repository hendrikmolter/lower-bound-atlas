Cycle Packing by treewidth under ETH

Statement

No deterministic algorithm decides Cycle Packing within the stated running time.

2o(t⁢log2⁢t)⁢n𝒪(1)2^(o(t log₂ t)) n^(O(1))

  • t — treewidth of the input graph
  • n — the number of vertices of G
