Square-root exponent in the solution budget under ETH

Statement

No deterministic algorithm solves Planar Dominating Set within the stated running time.

2o(k1/2)⁢B𝒪(1)2^(o(k^(1/2))) B^(O(1))

  • k — dominating-set budget
  • B — complete input length in bits
