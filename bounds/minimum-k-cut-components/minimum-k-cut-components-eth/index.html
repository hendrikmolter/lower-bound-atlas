Problems / Minimum k-Cut

Exponent in number of required components under ETH

Statement

No deterministic algorithm solves Minimum k-Cut within the stated running time.

f(k)⁢no(k)⁢B𝒪(1)f(k) n^(o(k)) B^(O(1))

The parameter factor f is an arbitrary computable function.

  • k — required number of connected components
  • n — number of vertices of the input graph
  • B — complete explicit binary input length
