Exponent in supplied pathwidth under ETH

Statement

No deterministic algorithm solves Maximum Cycle Cover within the stated running time.

2o(p⁢log2(p+2))⁢B𝒪(1)2^(o(p log₂(p+2))) B^(O(1))

  • p — width of the supplied path decomposition
  • B — complete explicit binary input length
