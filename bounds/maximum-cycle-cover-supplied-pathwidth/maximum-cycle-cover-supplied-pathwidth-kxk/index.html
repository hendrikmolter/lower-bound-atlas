Maximum Cycle Cover under the k×kk × k Clique Hypothesis

Statement

No deterministic algorithm decides Maximum Cycle Cover within the stated running time.

2o(p⁢log2(p+2))⁢B𝒪(1)2^(o(p log₂(p+2))) B^(O(1))

  • p — width of the supplied path decomposition
  • B — complete explicit binary input length

Derivation from the cited sources

The Cycle Packing lower bound under this hypothesis combines with the reduction in Lemma C.22. The reduction attaches a private three-vertex path and its closing edges at each vertex. A spanning cycle cover uses either a private triangle or a private four-cycle through the attachment vertex. The threshold increases by the original number of vertices, the complete output size grows polynomially, and the supplied width increases by at most three.

Recovery of a historical ETH bound

Recovered · ETH target: Exponent in supplied pathwidth

The packing-to-cover reduction preserves the historical supplied-width exponent scale, the unrestricted little-o rate and the polynomial factor in complete input length.
