Subexponential bound at distance one from a cluster graph under ETH

Statement

Input restrictions
  • The minimum number of vertices whose deletion leaves a disjoint union of cliques is one.

No deterministic algorithm solves Graph Motif within the stated running time.

2o(n)2^(o(n))

  • n — number of vertices in the input graph
