Exponent sublinear in the square root of the parameter under ETH

Statement

No deterministic algorithm solves Unit Disk Dominating Set within the stated running time.

f(k)⁢no(k1/2)f(k) n^(o(k^(1/2)))

  • k — dominating-set budget
