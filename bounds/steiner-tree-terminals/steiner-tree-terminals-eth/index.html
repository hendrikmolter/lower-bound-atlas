Problems / Steiner Tree

Steiner Tree by terminal count under ETH

Statement

Problem domain
  • The graph is finite, simple, undirected and unweighted.
Input restrictions
  • The graph is planar.

No deterministic algorithm decides Steiner Tree within the stated running time.

2o(k)⁢B𝒪(1)2^(o(k)) B^(O(1))

  • k — number of terminals
  • B — complete input length in bits

ETH ⇒ Statement

  • On Subexponential Parameterized Algorithms for Steiner Tree and Directed Subset TSP on Planar Graphs · Dániel Marx, Marcin Pilipczuk, Michał Pilipczuk · FOCS 2018, pp. 474–484 · Theorem I.2, p. 475 · Open full text
Derivation from the cited sources

The published theorem writes the polynomial factor in graph order n. On standard explicit unweighted inputs, one can normalize the budget to at most n−1n − 1 and relabel vertices, so all threshold queries have length polynomial in n. Polynomially many such queries recover the minimum cost.
