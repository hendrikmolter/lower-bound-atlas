Fixed-power bounds under SH

Statement

No deterministic algorithm decides Chromatic Number within the stated running time.

2𝒪(k1−ε)⁢N𝒪(1)2^(O(k^(1−ε))) N^(O(1))

For every fixed 0<ε<10 < ε < 1.

  • k — minimum size of a vertex cover of G
  • N — complete binary input length

Recovery of a historical ETH bound

Exponent degree recovered · ETH target: Slightly superexponential bound

SH excludes every fixed exponent power below one in the vertex cover number k. This recovers degree one. The historical little-o family at k⁢log2⁢kk log₂ k remains unrecovered.
