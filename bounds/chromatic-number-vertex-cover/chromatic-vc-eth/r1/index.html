Problems / Chromatic Number

Slightly superexponential bound under ETH

Statement

No deterministic algorithm decides Chromatic Number within the stated running time.

2o(k⁢log2⁢k)⁢n𝒪(1)2^(o(k log₂ k)) n^(O(1))

  • k — minimum size of a vertex cover of G
  • n — number of vertices of G

ETH ⇒ Statement

  • Slightly Superexponential Parameterized Problems · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · SIAM J. Comput. 47(3) (2018), 675–702 · Theorem 6.1, p. 698
