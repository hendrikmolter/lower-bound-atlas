Clique by solution size under ETH

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Clique within the stated running time.

f(k)⁢no(k)f(k) n^(o(k))

The bound excludes every computable prefactor f.

  • f — a computable parameter-dependent prefactor
  • k — requested clique size
  • n — number of vertices
