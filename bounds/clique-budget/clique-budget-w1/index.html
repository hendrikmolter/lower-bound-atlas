Clique by solution size under FPT ≠ W[1]

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

Input restrictions
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Clique within the stated running time.

f(k)⁢B𝒪(1)f(k) B^(O(1))

The bound excludes every computable prefactor f.

  • f — a computable parameter-dependent prefactor
  • k — requested clique size
  • B — complete input length in bits

W[1]-completeness applies to the threshold decision question because a clique of size at least k has a subset of exactly k vertices.
