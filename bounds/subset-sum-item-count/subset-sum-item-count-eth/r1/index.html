Subset Sum by item count under ETH

Statement

Input restrictions
  • Each item and the target is strictly positive. Equal item values may occur at different indices.

No deterministic algorithm decides Subset Sum within the stated running time.

2o(p)⁢B𝒪(1)2^(o(p)) B^(O(1))

  • p — number of indexed input items
  • B — complete input length in bits

The reduction has a linear number of items in the combined number of variables and clauses. Its item bit lengths are polynomial, so the ETH argument also excludes a fixed polynomial factor in the complete input length.

ETH ⇒ Statement

  • Polynomial kernels for weighted problems · Michael Etscheid, Stefan Kratsch, Matthias Mnich, Heiko Röglin · Journal of Computer and System Sciences 84 (2017), pp. 1–10 · Lemma 13 and proof, §3, p. 8
