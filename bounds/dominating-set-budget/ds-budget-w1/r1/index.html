Dominating Set by solution size under FPT ≠ W[1]

Statement

No lower bound recorded for this parameterization beyond W[2]-hardness.

Input restrictions
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Dominating Set within the stated running time.
