Exponent in solution budget under the k×kk × k Clique Hypothesis

Statement

No deterministic algorithm solves Independent Set of unit disks within the stated running time.

f(k)⁢no(k1/2)⁢B𝒪(1)f(k) n^(o(k^(1/2))) B^(O(1))

The parameter factor f is an arbitrary computable function.

The hard instances have coordinates of polynomial bit length in the number of objects.

  • k — solution budget
  • n — number of supplied geometric objects
  • B — complete explicit binary input length
