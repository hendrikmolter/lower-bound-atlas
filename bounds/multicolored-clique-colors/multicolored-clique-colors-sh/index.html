Multicolored Clique by number of color classes under SH

Statement

Problem domain
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Multicolored Clique within the stated running time.

2k𝒪(1)⁢n𝒪(k1−ε)2^(k^(O(1))) n^(O(k^(1−ε)))

For each fixed ε strictly between zero and 1.

  • k — number of color classes
  • n — number of vertices
  • ε — a fixed positive saving in the exponent

Derivation from the cited sources

The clause-grouping graph in the source already has one independent color class per group. A clique of size k uses exactly one vertex from every class.
