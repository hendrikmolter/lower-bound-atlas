Multicolored Clique by number of color classes under the k×kk × k Clique Hypothesis

Statement

Input restrictions
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Multicolored Clique within the stated running time.

f(k)⁢no(k)f(k) n^(o(k))

The bound excludes every computable prefactor f.

  • f — a computable parameter-dependent prefactor
  • k — number of color classes
  • n — number of vertices

The square hypothesis gives the stated exclusion for Clique. The color-copy construction preserves k and multiplies the graph order by k, which can be absorbed into the computable prefactor.
