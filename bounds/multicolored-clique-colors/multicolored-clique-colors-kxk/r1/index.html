Multicolored Clique by number of color classes under the k×kk × k Clique Hypothesis

Statement

Input restrictions
  • The graph is finite, simple, undirected, and unweighted.

No deterministic algorithm decides Multicolored Clique within the stated running time.

f(k)⁢no(k)f(k) n^(o(k))

The bound excludes every computable prefactor f.

  • f — a computable parameter-dependent prefactor
  • k — number of color classes
  • n — number of vertices

The square hypothesis gives the stated exclusion for Clique. The color-copy construction preserves k and multiplies the graph order by k, which can be absorbed into the computable prefactor.

k × k Clique Hypothesis ⇒ Statement

  • After ETH: the k×kk×k Clique Hypothesis · Stefan Szeider · Zenodo preprint v3, 9 November 2026 · Proposition 1, Section 3 and Table 1, second row · Open full text
  • On the parameterized complexity of multiple-interval graph problems · Michael R. Fellows, Danny Hermelin, Frances Rosamond, Stéphane Vialette · Theoretical Computer Science 410(1) (2009), 53–61 · Section 2, Lemma 1, p. 56

Recovery of a historical ETH bound

Recovered · ETH target: Exponent sublinear in the number of color classes

The historical and square-hypothesis bounds exclude the same unrestricted deterministic time family, with total graph order as the exponent base and every computable prefactor.
