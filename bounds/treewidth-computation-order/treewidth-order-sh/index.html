Treewidth computation by graph order under SH

Statement

Input restrictions
  • The graph is finite, simple and undirected.

No deterministic algorithm decides Treewidth computation within the stated running time.

2𝒪(n1−ε)⁢B𝒪(1)2^(O(n^(1−ε))) B^(O(1))

For each fixed ε strictly between zero and 1.

  • n — number of vertices
  • ε — a fixed positive saving in the exponent
  • B — complete input length in bits
