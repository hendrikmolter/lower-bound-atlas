Treewidth computation by graph order under ETH

Statement

Input restrictions
  • The graph is finite, simple and undirected.

No deterministic algorithm decides Treewidth computation within the stated running time.

𝒪(2δ⁢n⁢BC)O(2^(δ n) B^C)

There exists δ>0δ > 0 such that the exclusion holds for every fixed C≥0C ≥ 0.

  • n — number of vertices
  • δ — a positive exponent coefficient
  • C — a fixed polynomial input exponent
  • B — complete input length in bits

The proof distinguishes two adjacent treewidth thresholds on graphs with a linear number of vertices from bounded-occurrence 3-SAT. The journal and checked author version use different theorem numbers.
