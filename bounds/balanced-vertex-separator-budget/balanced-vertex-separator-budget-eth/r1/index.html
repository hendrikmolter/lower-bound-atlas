Balanced Vertex Separator under ETH: Sublinear exponent in the budget

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

f(k)⁢No(k)f(k) N^(o(k))

For every computable function f.

  • k — solution budget
  • N — the explicit input size in the source
