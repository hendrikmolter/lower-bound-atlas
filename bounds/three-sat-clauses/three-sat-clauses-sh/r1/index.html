3SAT under SH: Fixed-power exclusion

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

2𝒪(m1−ε)⁢B𝒪(1)2^(O(m^(1−ε))) B^(O(1))

For each fixed 0<ε<10<ε<1.

  • m — number of clauses
  • B — complete explicit binary input length

Deleting unused variables gives at most 3m occurring variables. The reverse bound uses the sparse clause-count comparison in Corollary 2.3.
