Every fixed power below one half under SH

Statement

No deterministic algorithm solves Planar Hamiltonian Cycle within the stated running time.

2𝒪(n1/2−ε)⁢B𝒪(1)2^(O(n^(1/2−ε))) B^(O(1))

Separately for each fixed 0<ε<1/20 < ε < 1/2.

  • n — number of vertices
  • B — complete input length in bits
  • ε — fixed exponent loss
