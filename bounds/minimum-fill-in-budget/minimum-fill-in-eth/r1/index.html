Fixed-power bound below the square-root exponent under ETH

Statement

No deterministic algorithm solves Minimum Fill-In within the stated running time.

2𝒪(k1/2−δ)⁢n𝒪(1)2^(O(k^(1/2−δ))) n^(O(1))

For every fixed δ>0δ>0.

  • k — maximum number of edges that may be added
  • δ — fixed positive exponent saving
  • n — number of vertices in the input graph
