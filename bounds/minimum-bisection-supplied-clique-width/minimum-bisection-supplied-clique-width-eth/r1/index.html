Sublinear exponent in the expression width under ETH

Statement

Problem domain
  • The input graph has an even number of vertices.

No deterministic algorithm solves Minimum Bisection within the stated running time.

f(t)⁢no(t)f(t) n^(o(t))

For every computable function f.

  • t — width of the supplied clique-width expression
  • n — number of vertices in the input graph

ETH ⇒ Statement

  • Almost Optimal Lower Bounds for Problems Parameterized by Clique-Width · Fedor V. Fomin, Petr A. Golovach, Daniel Lokshtanov, Saket Saurabh · SIAM Journal on Computing 43(5) (2014), pp. 1541–1563 · Corollary 4.8 and proof, p. 1557 · Open full text
