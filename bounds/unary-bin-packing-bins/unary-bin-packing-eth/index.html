Problems / Unary Bin Packing

Exponent sublinear in k/log⁢kk / log k under ETH

Statement

No deterministic algorithm solves Unary Bin Packing within the stated running time.

f(k)⁢No(k/log2⁢k)f(k) N^(o(k / log₂ k))

For every computable function f.

  • k — maximum number of available bins
  • N — total unary input length

ETH ⇒ Statement

  • Bin Packing with Fixed Number of Bins Revisited · Klaus Jansen, Stefan Kratsch, Dániel Marx, Ildikó Schlotter · Journal of Computer and System Sciences 79(1) (2013), pp. 39–49 · Theorem 3 and proof, p. 48
