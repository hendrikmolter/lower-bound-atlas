Planar Vertex Cover by solution size under SH

Statement

Input restrictions
  • The graph is finite, simple, undirected, and unweighted.
  • The graph is planar.

No deterministic algorithm decides Planar Vertex Cover within the stated running time.

2𝒪(k1/2−ε)⁢B𝒪(1)2^(O(k^(1/2−ε))) B^(O(1))

For each fixed ε strictly between zero and 1/2.

  • k — solution threshold
  • ε — a fixed positive saving in the exponent
  • B — complete input length in bits
