Effective linear-exponent bound under FPT ≠ W[1]

Statement

Problem domain
  • All input strings have the same length L.
Input restrictions
  • L=d+1L=d+1
  • q=d+4q=d+4

No deterministic algorithm decides Closest String within the stated running time.

2oeff(d)⁢N𝒪(1)2^(o_eff(d)) N^(O(1)) Effective little-o

  • d — Hamming radius
  • N — Input length in bits.
  • L — common word length
  • q — number of distinct symbols used in the input words

FPT ≠ W[1] ⇒ Statement

  • CNF-SAT source · On the Existence of Subexponential Parameterized Algorithms · Liming Cai, David Juedes · JCSS 67(4) (2003), 789–807 · Lemma 3.1 and Corollary 3.1 (Section 3). The paired-variable CNF-SAT source reduces to ordinary CNF-SAT on the same variables by adding the two clauses enforcing exactly one true variable in each pair.
  • Closest String construction · Slightly Superexponential Parameterized Problems · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · SIAM J. Comput. 47(3) (2018), 675–702 · Theorem 3.1, proof in Section 3.1. Specialize the word construction to two truth-value symbols.
Derivation from the cited sources

Add opposite unit clauses on two fresh variables. With L=n+2L=n+2 positions and L+1L+1 filler symbols, the two clauses ensure that both truth values and all fillers occur, giving q=d+4q=d+4. Some filler is absent from every length-L center. The words using that filler require a satisfying literal in every clause. Conversely, a satisfying assignment agrees with every word. The encoding is polynomial and d=n+1d=n+1 preserves the effective exponent scale.

Recovery of a historical ETH bound

Recovered up to a logarithmic factor in the exponent (effective little-o) · ETH target: Subexponential-time bound

The recovered exponent scale is d, a logarithmic factor below the historical scale d⁢log2⁢dd log₂ d, and requires effective convergence.
