Explicit-table CSP under ETH: Sublinear exponent in treewidth

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

f(t)⁢No(t)f(t) N^(o(t))

For every computable f.

  • t — treewidth of the primal graph
  • N — size of the explicit constraint instance

ETH ⇒ Statement
