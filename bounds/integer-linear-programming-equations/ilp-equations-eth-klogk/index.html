Subexponential bound in k⁢log⁢kk log k under ETH

Statement

Input restrictions
  • Every entry of A is either zero or one.
  • The vector b is nonnegative, and both the number of columns ℓ and the maximum entry of b are 𝒪(k⁢log2⁢k)O(k log₂ k).

No deterministic algorithm solves Integer Linear Programming Feasibility within the stated running time.

2o(k⁢log2⁢k)⁢N𝒪(1)2^(o(k log₂ k)) N^(O(1))

  • k — number of rows of A
  • N — total bit length of the input

On the hard instances the explicit input length is polynomial in k, so a fixed polynomial factor is absorbed in the exponent.

ETH ⇒ Statement

  • Tight Complexity Lower Bounds for Integer Linear Programming with Few Constraints · Dušan Knop, Michał Pilipczuk, Marcin Wrochna · ACM Transactions on Computation Theory 12(3) (2020), Article 19 · Theorem 1, p. 19:4, and proof in §2.3, pp. 19:9–19:10
