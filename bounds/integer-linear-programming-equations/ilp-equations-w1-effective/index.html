All-ones right-hand-side integer programming under FPT ≠ W[1]

Statement

Input restrictions
  • Every entry of A is either zero or one.
  • Every entry of the right-hand side b equals one.
  • Every column of A has a nonzero entry. Consequently every feasible coordinate of x is zero or one.

No deterministic algorithm decides feasibility of Ax=b for the stated all-ones right-hand side within the stated running time.

2h(k)⁢NC2^(h(k)) N^C

For every fixed C≥0C ≥ 0 and every finite nonnegative function h, assume there is a computable threshold function T with h(k)≤k/jh(k) ≤ k/j for every positive integer j and every k≥T(j)k ≥ T(j).

The function h itself need not be computable.

  • k — number of rows of A
  • h — finite nonnegative exponent function with the stated computable convergence cutoff
  • N — total bit length of the input
  • C — fixed nonnegative exponent of the complete input length

The column count is unrestricted. The proof uses Lin’s incidence matrix with exact-one rows in place of covering constraints.

Recovery of a historical ETH bound

Recovered up to a logarithmic factor in the exponent (effective little-o) · ETH target: Subexponential bound in k⁢log⁢kk log k for binary coefficients

The new bound applies to the subclass with all-ones right-hand side and nonzero columns. Any solver for the general binary-coefficient task must handle this subclass. The W[1] exclusion is therefore a logarithmic recovery for the general task, using a computable convergence cutoff and an arbitrary fixed polynomial in the complete input length. The ETH k⁢log2⁢kk log₂ k exclusion concerns general right-hand sides. The all-ones subclass has a⁢2k⁢N𝒪(1)a 2^k N^(O(1)) subset algorithm.
