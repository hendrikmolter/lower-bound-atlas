All-ones right-hand-side integer programming under FPT ≠ W[1]

Statement

Input restrictions
  • Every entry of A is either zero or one.
  • Every entry of the right-hand side b equals one.
  • Every column of A has a nonzero entry. Consequently every feasible coordinate of x is zero or one.

No deterministic algorithm decides feasibility of Ax=b for the stated all-ones right-hand side within the stated running time.

2oeff(k)⁢NC2^(o_eff(k)) N^C Effective little-o

For every fixed C≥0C ≥ 0.

  • k — number of rows of A
  • N — total bit length of the input
  • C — fixed nonnegative exponent of the complete input length

FPT ≠ W[1] ⇒ Statement

  • A Simple Gap-Producing Reduction for the Parameterized Set Cover Problem · Bingkai Lin · ICALP 2019, LIPIcs 132, 81:1–81:15 · Lemma 14 and proof, §3.4, pp. 81:11–81:12 · Open full text
Derivation from the cited sources

In Lin’s construction, the universe size equals the Set Cover budget times the common set size. A cover within budget is therefore an exact cover, and each exact cover meets the budget. The binary incidence matrix encodes exact cover as Ax=1 with a nonzero column for every set. Its O(h³ log n) rows allow the effective exponent cutoff to give a fixed-parameter algorithm for Multicolored Clique.

Recovery of a historical ETH bound

Recovered up to a logarithmic factor in the exponent (effective little-o) · ETH target: Subexponential bound in k⁢log⁢kk log k for binary coefficients

The all-ones incidence matrices are valid inputs to the binary-coefficient task with general right-hand sides. The exclusion on those matrices gives a logarithmic-scale recovery for that task, with computable convergence cutoffs and a fixed polynomial input factor.
