Balanced-alphabet bound under the k×kk × k Clique Hypothesis

Statement

Problem domain
  • All input strings have the same length L.
Input restrictions
  • L=d+1L=d+1
  • q=2⁢d+3q=2d+3

No deterministic algorithm decides Closest String within the stated running time.

2o(d⁢log2⁢d)⁢N𝒪(1)2^(o(d log₂ d)) N^(O(1))

  • d — Hamming radius
  • N — input length in bits

k × k Clique Hypothesis ⇒ Statement

  • Slightly Superexponential Parameterized Problems · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · SIAM J. Comput. 47(3) (2018), 675–702 · Corollary 2.6, Lemma 2.8 and Theorems 2.11, 2.12 and 3.1, pp. 681–687
Derivation from the cited sources

The reduction sets L=d+1L = d + 1 and uses 2⁢L+12L + 1 ordinary and dummy symbols in total. The strings for the diagonal-block row sets use every one of those symbols, giving q=2⁢d+3q = 2d + 3.
