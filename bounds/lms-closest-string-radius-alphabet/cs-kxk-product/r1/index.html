Problems / Closest String

Subexponential-time bound under k×kk × k Clique Hypothesis

Statement

Input restrictions
  • All input strings have the same length L.

No deterministic algorithm decides Closest String within the stated running time.

2o(d⁢log2⁢q)⁢N𝒪(1)2^(o(d log₂ q)) N^(O(1))

  • d — Hamming radius
  • q — number of distinct symbols occurring in the input strings
  • N — input length in bits
