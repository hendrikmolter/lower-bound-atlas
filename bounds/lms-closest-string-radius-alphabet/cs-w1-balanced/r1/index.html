Problems / Closest String

One agreement with a balanced alphabet under FPT ≠ W[1]

Statement

Problem domain
  • All input strings have the same length L.
Input restrictions
  • L=d+1L=d+1
  • q=2⁢d+3q=2d+3

No deterministic algorithm decides Closest String within the stated running time.

2oeff(d)⁢NC2^(o_eff(d)) N^C Effective little-o

There is no alphabet-dependent prefactor.

The exponent is a nonnegative integer-valued function with a computable upper bound.

  • d — Hamming radius
  • N — input length in bits
  • C — fixed nonnegative constant

FPT ≠ W[1] ⇒ Statement

  • CNF-SAT source · On the Existence of Subexponential Parameterized Algorithms · Liming Cai, David Juedes · JCSS 67(4) (2003), 789–807 · Lemma 3.1 and Corollary 3.1.
  • Closest String construction · Slightly Superexponential Parameterized Problems · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · SIAM J. Comput. 47(3) (2018), 675–702 · Theorem 3.1 and its proof in Section 3.1.
Derivation from the cited sources

Encode the requirement that exactly one variable in each pair is true by two CNF clauses per pair, preserving the variable count n. Specialize the word construction to two truth-value symbols. Add opposite unit clauses on two fresh variables. With L=n+2L=n+2 positions and 2⁢L−12L−1 filler symbols, the two clauses ensure that both truth values and all fillers occur, giving q=2⁢d+3q=2d+3. For each length-L center, some filler is absent. The words using that filler require a satisfying literal in every clause. Conversely, a satisfying assignment agrees with every word. The encoding is polynomial and d=n+1d=n+1 preserves the effective exponent scale.

Recovery of a historical ETH bound

Recovered up to a logarithmic factor in the exponent (effective little-o) · ETH target: Subexponential-time bound with a balanced alphabet

On the balanced inputs of the historical bound, dividing the exponent scale by log₂ d gives d. The exclusion at this scale requires effective convergence.
