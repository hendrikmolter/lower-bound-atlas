Subexponential bound in the number of edges under ETH

Statement

Input restrictions
  • The input graph has maximum degree at most six.

No deterministic algorithm solves Cluster Editing within the stated running time.

2o(m)2^(o(m))

  • m — number of edges in the input graph

The reduction produces normalized explicit instances whose encoding size is polynomial in the source formula size. Its hardness proof also excludes adding a fixed polynomial input factor.
