Strongly Connected Steiner Subgraph under FPT ≠ W[1]: Fixed-parameter tractability

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

No deterministic algorithm solves this decision problem within the stated running time.

f(k)⁢B𝒪(1)f(k) B^(O(1))

The parameter factor f is an arbitrary computable function and the exponent of B is an arbitrary fixed constant.

  • k — solution vertex budget
  • B — complete binary input length

The reduction bounds the total number of selected vertices, including terminals, in an unweighted directed graph.
