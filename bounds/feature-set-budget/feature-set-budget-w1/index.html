Feature Set under FPT ≠ W[1]: Linear-reduction lower bound

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

f(k)⁢No(k)⁢M𝒪(1)f(k) N^(o(k)) M^(O(1))

For any recursive f subject to the source convention that the complexity functions and their inverses be easily computable.

  • k — number of selected features
  • N — number of available features
  • M — complete encoding size

The source gives hardness for the second level of the linear-reduction hierarchy and thereby the stated consequence under FPT ≠ W[1]. Standard W[2]-hardness alone does not supply this exponent.

FPT ≠ W[1] ⇒ Statement

  • On the computational hardness based on linear FPT-reductions · Jianer Chen, Xiuzhen Huang, Iyad A. Kanj, Ge Xia · Journal of Combinatorial Optimization 11(2) (2006), 231–247 · Theorems 2.2 and 4.1(1), pp. 235 and 239–240, and footnote 1, p. 231
