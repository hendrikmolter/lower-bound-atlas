Feature Set under FPT ≠ W[1]: Sublinear exponent in the feature count

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

No(k)⁢M𝒪(1)N^(o(k)) M^(O(1))

  • k — number of selected features
  • N — number of available features
  • M — complete encoding size
