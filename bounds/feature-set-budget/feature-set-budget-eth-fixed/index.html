Feature Set under ETH: Sublinear exponent in the feature count

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

No(k)⁢M𝒪(1)N^(o(k)) M^(O(1))

  • k — number of selected features
  • N — number of available features
  • M — complete encoding size

ETH ⇒ Statement

  • Tight Lower Bounds for Certain Parameterized NP-Hard Problems · Jianer Chen, Benny Chor, Mike Fellows, Xiuzhen Huang, David Juedes, Iyad A. Kanj, Ge Xia · Information and Computation 201(2) (2005), 216–231 · Theorem 3.5 and Feature Set definition, pp. 225–227
  • On the computational hardness based on linear FPT-reductions · Jianer Chen, Xiuzhen Huang, Iyad A. Kanj, Ge Xia · Journal of Combinatorial Optimization 11(2) (2006), 231–247 · §6, discussion preceding Theorem 6.2, p. 246
Derivation from the cited sources

This follows from the earlier W[1] bound and the source implication from ordinary ETH, with the same candidate space and without a parameter-dependent prefactor.
