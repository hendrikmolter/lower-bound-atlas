Fixed-width SAT under SH: Fixed-power exclusion

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

2𝒪(s1−ε)⁢B𝒪(1)2^(O(s^(1−ε))) B^(O(1))

For each fixed integer r≥3r≥3 and each fixed 0<ε<10<ε<1.

  • s — sum of the numbers of declared variables and clauses
  • r — the fixed width bound
  • B — complete explicit binary input length

At fixed width the sum of clauses and declared variables also bounds the number of literal occurrences.
