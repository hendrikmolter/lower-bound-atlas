Double-exponential dependence on the clique budget under ETH

Statement

No deterministic algorithm decides Edge Clique Cover within the stated running time.

22o(k)⁢n𝒪(1)2^(2^(o(k))) n^(O(1))

  • k — allowed number of covering cliques
  • n — the number of vertices of G
