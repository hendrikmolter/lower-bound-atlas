Problems / Planar Strongly Connected Steiner Subgraph

Exponent sublinear in the square root of the parameter under ETH

Statement

Input restrictions
  • Every arc has weight one.

No deterministic algorithm solves Planar Strongly Connected Steiner Subgraph within the stated running time.

f(k)⁢no(k1/2)f(k) n^(o(k^(1/2)))

  • f — arbitrary total computable parameter function
  • k — number of terminals
  • n — number of vertices
