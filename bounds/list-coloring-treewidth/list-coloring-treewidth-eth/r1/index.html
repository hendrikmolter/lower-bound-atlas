Problems / List Coloring

Exponent in treewidth under ETH

Statement

No deterministic algorithm solves List Coloring within the stated running time.

f(t)⁢Bo(t)f(t) B^(o(t))

The parameter factor f is an arbitrary computable function.

  • t — treewidth of the input graph
  • B — complete explicit binary input length
