Problems / List Coloring

Subexponential bound in treewidth under ETH · Fixed common palette

Statement

Input restrictions
  • The available palette is [q]. Every vertex list is a subset of this same palette.

No deterministic algorithm decides List Coloring within the stated running time.

2o(t)⁢n𝒪(1)2^(o(t)) n^(O(1))

For every fixed integer q≥3q ≥ 3.

  • t — treewidth of the input graph
  • n — number of vertices of G

ETH ⇒ Statement

  • Lower bounds based on the Exponential Time Hypothesis · Daniel Lokshtanov, Dániel Marx, Saket Saurabh · Bulletin of the EATCS 105 (2011), 41–71 · Theorem 3.2, PDF p. 12 · Open full text
Derivation from the cited sources

Give every vertex of a 3-Coloring instance the list {1, 2, 3}, a subset of the fixed palette [q]. The graph and treewidth are unchanged. A treewidth-subexponential algorithm would also be subexponential in the number of vertices, since treewidth is at most the graph order.
