Fixed-width SAT under the k×kk × k Clique Hypothesis: Bound for fixed even clause width

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

2o(na/(a+1)⁢log2⁢n)⁢B𝒪(1)2^(o(n^(a/(a+1)) log₂ n)) B^(O(1))

Separately for each fixed integer a≥2a≥2, with the fixed clause-width bound r=2⁢ar=2a.

  • n — number of declared variables
  • r — the fixed width bound
  • B — complete explicit binary input length
