Fixed-width SAT under ETH: Subexponential-time bound

Statement

No deterministic algorithm solves the stated decision problem within the stated running time.

2o(n)⁢B𝒪(1)2^(o(n)) B^(O(1))

For every fixed integer r≥3r≥3.

  • n — number of declared variables
  • r — the fixed width bound
  • B — complete explicit binary input length

ETH ⇒ Statement

  • Which Problems Have Strongly Exponential Complexity? · Russell Impagliazzo, Ramamohan Paturi, Francis Zane · JCSS 63(4) (2001), 512–530 · Corollary 1 and Theorem 3 · Open full text
