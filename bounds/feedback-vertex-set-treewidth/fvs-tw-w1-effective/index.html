Effective little-o bound in the treewidth under FPT ≠ W[1]

Statement

No deterministic algorithm decides Feedback Vertex Set within the stated running time.

2oeff(t)⁢B𝒪(1)2^(o_eff(t)) B^(O(1)) Effective little-o

  • t — treewidth of the input graph
  • B — complete binary input length

FPT ≠ W[1] ⇒ Statement

  • XNLP-Completeness for Parameterized Problems on Graphs with a Linear Structure · Hans L. Bodlaender, Carla Groenland, Hugo Jacob, Lars Jaffke, Paloma T. Lima · Algorithmica 87 (2025), 465–506 · Theorem 6 and §4.3, Lemma 5 and Claim 15
Derivation from the cited sources

Logarithmic-pathwidth Feedback Vertex Set is XNLP-hard, so it is W[1]-hard. A graph’s treewidth is at most the width of the supplied path decomposition, which can be discarded. For a Clique input of order n and parameter k, the output treewidth is at most g(k)⁢(1+log2⁢n)g(k)(1+log₂ n) for a computable g. Use the computable cutoff for a slope at most 1/g(k)1/g(k). Above the cutoff the exponential factor is polynomial in n, and below it the computable exponent has a finite maximum controlled by k. The polynomial-size reduction output then gives an FPT algorithm for Clique.
