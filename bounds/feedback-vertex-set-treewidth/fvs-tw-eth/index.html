Exponential dependence on treewidth under ETH

Statement

No deterministic algorithm decides Feedback Vertex Set within the stated running time.

2o(t)⁢B𝒪(1)2^(o(t)) B^(O(1))

  • t — treewidth of the input graph
  • B — complete binary input length

Derivation from the cited sources

Add one private vertex adjacent to both ends of each edge of the Vertex Cover instance. A cover leaves a forest. Conversely, any feedback vertex set hits each edge triangle, so replacing any selected private vertex with an endpoint yields a cover of no larger size. A bag for each private vertex and its endpoints gives treewidth at most max(n−1,2)max(n−1, 2) for original order n, with polynomial encoding size.
