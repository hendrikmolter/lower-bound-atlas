Edge Dominating Set by intrinsic clique-width under FPT ≠ W[1]

Statement

No lower bound recorded for this parameterization beyond W[1]-hardness.

No deterministic algorithm solves Edge Dominating Set, measured by intrinsic clique-width, within the stated running time.

f(t)⁢B𝒪(1)f(t) B^(O(1))

For every computable f.

  • t — intrinsic clique-width of the graph
  • B — complete explicit binary input length
