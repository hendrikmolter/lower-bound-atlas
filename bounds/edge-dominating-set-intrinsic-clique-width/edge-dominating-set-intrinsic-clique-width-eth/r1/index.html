Edge Dominating Set by intrinsic clique-width under ETH

Statement

No deterministic algorithm solves Edge Dominating Set, measured by intrinsic clique-width, within the stated running time.

f(t)⁢no(t)f(t) n^(o(t))

For every computable f.

  • t — intrinsic clique-width of the graph
  • n — number of vertices

ETH ⇒ Statement

  • Almost Optimal Lower Bounds for Problems Parameterized by Clique-Width · Fedor V. Fomin, Petr A. Golovach, Daniel Lokshtanov, Saket Saurabh · SIAM Journal on Computing 43(5) (2014), pp. 1541–1563 · Theorem 5.1, p. 1558 · Open full text

Source note

The source theorem excludes the graph-order clock even when an expression of bounded width is available. An intrinsic-clock algorithm would also accept those graphs, as intrinsic clique-width is at most the supplied width. A nondecreasing majorant of a sublinear exponent remains sublinear.
