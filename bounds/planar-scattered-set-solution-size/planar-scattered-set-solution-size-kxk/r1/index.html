Exponent sublinear in the square root of the parameter under k×kk × k Clique Hypothesis

Statement

No deterministic algorithm solves Planar Scattered Set within the stated running time.

f(k)⁢no(k1/2)f(k) n^(o(k^(1/2)))

  • f — arbitrary total computable parameter function
  • k — number of selected vertices
  • n — number of vertices
