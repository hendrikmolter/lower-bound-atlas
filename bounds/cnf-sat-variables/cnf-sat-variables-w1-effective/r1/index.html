Effective subexponential-time exclusion under FPT ≠ W[1]

Statement

No deterministic algorithm decides CNF-SAT within the stated running time.

2oeff(n)⁢L𝒪(1)2^(o_eff(n)) L^(O(1)) Effective little-o

  • n — number of occurring variables
  • L — complete binary formula input length

FPT ≠ W[1] ⇒ Statement

  • On the Existence of Subexponential Parameterized Algorithms · Liming Cai, David Juedes · JCSS 67(4) (2003), 789–807 · Lemma 3.1 and Corollary 3.1, §3, pp. 796–799
Derivation from the cited sources

For each paired variable pair in the Cai–Juedes construction, two CNF clauses enforce exactly one true variable without adding variables. The CNF has 𝒪(h⁢log⁢r)O(h log r) variables for source weight h and r source variables. A computable exponent cutoff then bounds CNF-SAT time by a fixed power of r times a computable function of h, which would decide the W[1]-hard source problem in FPT time.
