Cycle Packing by supplied path width under ETH

Statement

No deterministic algorithm decides Cycle Packing within the stated running time.

2o(p⁢log2⁢p)⁢B𝒪(1)2^(o(p log₂ p)) B^(O(1))

  • p — width of the supplied path decomposition
  • B — the input length in bits, including the decomposition
