Effective bound in width times its logarithm under FPT ≠ W[1]

Statement

Input restrictions
  • The graph is connected and bipartite with maximum degree at most six.
  • Treewidth equals pathwidth.
  • The girth is at least n1−γn^(1−γ).
  • The supplied path decomposition is optimal.

No deterministic algorithm decides Undirected Cycle Packing within the stated running time.

2oeff(p⁢log2⁢p)⁢N𝒪(1)2^(o_eff(p log₂ p)) N^(O(1))

For every fixed 0<γ<10<γ<1.

The exponent is a computable nonnegative integer function and has computable convergence to little-o at scale p⁢log2⁢pp log₂ p.

  • p — width of the supplied path decomposition
  • N — complete binary input length, including a supplied certificate if present
  • n — number of vertices of G
  • γ — fixed constant in the girth promise

The reduction sends compact Clique instances to connected graphs of large girth and produces an optimal path decomposition. Its explicit input length is polynomial in the per-instance host encoding for each fixed γ.
