Exponent in solution budget under FPT ≠ W[1]

Statement

No deterministic algorithm solves Hitting Set within the stated running time.

f(k)⁢ro(k)⁢B𝒪(1)f(k) r^(o(k)) B^(O(1))

The parameter factor f is an arbitrary computable function.

The exclusion remains valid on k≤μ(r)k ≤ μ(r) for every fixed nondecreasing unbounded μ.

  • k — solution budget
  • r — number of candidate elements in the ground set
  • B — complete explicit binary input length
