Exponent of complete input length under ETH

Statement

No deterministic algorithm solves Hitting Set within the stated running time.

f(k)⁢Bo(k)f(k) B^(o(k))

The parameter factor f is an arbitrary computable function.

  • k — solution budget
  • B — complete explicit binary input length
