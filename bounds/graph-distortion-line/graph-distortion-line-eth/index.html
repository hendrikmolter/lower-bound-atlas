Graph Distortion into a line under ETH: Subexponential-time bound in d⁢log⁢dd log d

Statement

Input restrictions
  • The target is the integer line.

No deterministic algorithm solves the stated decision problem within the stated running time.

2o(d⁢log2⁢d)⁢n𝒪(1)2^(o(d log₂ d)) n^(O(1))

  • d — allowed distortion
  • n — number of vertices
