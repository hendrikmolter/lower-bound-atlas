Graph Distortion into a line under FPT ≠ W[1]: Effective subexponential lower bound

Statement

Input restrictions
  • The graph is bipartite.

No deterministic algorithm solves the stated decision problem within the stated running time.

2h(d)⁢B𝒪(1)2^(h(d)) B^(O(1))

The exponent h is finite, nonnegative and o(d⁢log2⁢d)o(d log₂ d) with a computable convergence modulus.

  • d — allowed distortion
  • B — complete explicit binary input length
