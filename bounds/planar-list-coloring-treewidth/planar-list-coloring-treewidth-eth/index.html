Sublinear exponent in the parameter under ETH

Statement

No deterministic algorithm solves Planar List Coloring within the stated running time.

f(t)⁢no(t)f(t) n^(o(t))

  • f — arbitrary total computable parameter function
  • t — intrinsic treewidth
  • n — number of vertices
