Subexponential bound in the common part size under ETH

Statement

No deterministic algorithm solves Three-Dimensional Matching within the stated running time.

2o(q)⁢m𝒪(1)2^(o(q)) m^(O(1))

  • q — number of elements in each of the three sets
  • m — number of allowed triples

The reduction gives q=6⁢Mq=6M for a formula with M clauses. The set of distinct triples has size at most q³, so the displayed polynomial factor can be absorbed into the exponent.
